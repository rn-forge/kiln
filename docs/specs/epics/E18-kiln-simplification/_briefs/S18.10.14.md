# S18.10.14 — One distribution-name canonicaliser

Brief for
[S18.10.14](../F18.10-review-defects.md#s181014-one-distribution-name-canonicaliser),
at `feature/v1` after `7d4abbd`.

## Goal

Every distribution name kiln compares goes through packaging's
`canonicalize_name`, so `rn.forge.agentkit` is governed by the dependency
contract exactly like `rn-forge-agentkit`.

## Settled

- The one canonicaliser is `packaging.utils.canonicalize_name`; `packaging` is
  already a dependency and `devops/` already imports it. No new kiln helper is
  added. S18.7.3's shared parsing covers docs and task parsing, not names.
- In `src/rn_forge/kiln/modules/python/checks/rn_forge_deps.py`:
    - `distribution(requirement)` returns
      `canonicalize_name(match.group(1)) if match else ""`.
    - `governed(name)` compares `canonicalize_name(name)`.
    - `_check_allowed` builds `permitted` with `canonicalize_name(name)`, and
      `_check_required` compares `canonicalize_name(name)` to `declared`. Each
      replaces a bare `name.lower()`.
    - The scaffold (`python/pyproject.py`, `python/ranges.py`) already calls
      `distribution`, so it needs no edit.
- In `src/rn_forge/kiln/devops/ci.py`, delete `normalize` (a one-line wrapper of
  `canonicalize_name`). Its callers import `canonicalize_name` from
  `packaging.utils` instead: `devops/ci.py` (`releasable`), `devops/uv.py`
  (the eight calls and its import of `normalize`) and `devops/cli.py`
  (`ci.normalize(args.package)`). `requirement_name` stays.
- Rejected (do not build): a kiln-owned `canonical()` wrapper, and a regex that
  collapses `.` by hand.

## Current behaviour

- Probed: `distribution("rn.forge.agentkit>=0.6")` returns `rn.forge.agentkit`,
  because the regex lowercases and swaps `_` only. `governed` is then false,
  so a dependency group entry `rn.forge.agentkit>=0.6.0` in a `python-tool`
  repo gets no `deps.not-allowed` finding, where `rn-forge-agentkit>=0.6.0`
  does.
- Test 1 below therefore fails for the `rn.forge.agentkit` and
  `RN_Forge.AgentKit` rows (no finding), and passes for the control row.

## Change

- **Change:** the four source files above.
- **Overlap:** none with `devops/requirements.py` (it already calls
  `canonicalize_name` and is not edited), `cicd/config.py`, `tasks/config.py`,
  `tasks/checks/layout.py`, `docs/site.py` or `docs/structure.py`.
- **Leave alone:** `archetypes/__init__.py` (its `replace("_", "-")` names a
  directory, not a distribution).
