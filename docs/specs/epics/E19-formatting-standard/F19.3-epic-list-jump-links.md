`render_epics` writes the epic list's jump links as a bullet list, one range per
line, so mdformat leaves the derived region alone however many ranges there are.

## Context

`render_epics` writes all of a list's ranges on one line,
`Jump to: [E1–E10](#e1e10) · [E11–E20](#e11e20) · …`. With four ranges the line
is longer than 80 characters. mdformat, at the `wrap = 80` that kiln seeds in
`.mdformat.toml`, then wraps it. `kiln doctor` reads the wrapped region as
stale, and `task docs:generate` writes it back on one line. No state of the file
passes both `quality:lint:markdown` and `kiln:doctor`, so `task lint` cannot
pass.

pykit hit this when it added E31. Its committed `docs/specs/epics/index.md` is
the generator's output and fails mdformat. That blocks pykit Release 12, whose
exit criteria need `task lint` green. kiln has two ranges, and the existing
tests use one or two, so `_stable` never saw a line long enough to wrap.

The jump line is the only prose a derived region emits that grows with the
repository. The `**Stories:**` line is bounded by the four state counts, and
mdformat leaves tables, headings and markers alone.

## Design

**A list, not a wrapped line.** The region opens with:

```markdown
Jump to:

- [E1–E10](#e1e10)
- [E11–E20](#e11e20)
- [E21–E30](#e21e30)
- [E31–E40](#e31e40)
```

Each item is a short link, and mdformat leaves it alone at any `wrap` the
repository sets, including `keep` and `no`. The links, their order and the slugs
do not change. The headings and tables below the list do not change.

## Acceptance

S19.3.1 is the feature's only story, so its acceptance is the feature's. pykit
then moves its `[kiln] ref` to the commit that closes it and regenerates its
epic list. That is pykit's work, under its Release 12, and is not written here.

## Considered and rejected

- **Wrap the jump line at 80 in the generator.** It would match mdformat only at
  kiln's seeded `wrap = 80`. `.mdformat.toml` belongs to the repository, so a
  repository that changes `wrap` would hit the same loop.
- **Have `kiln doctor` compare the region with whitespace collapsed.** The file
  would still fail mdformat after every `task docs:generate`, so the loop
  stays.
- **Drop the jump line.** MkDocs's table of contents lists the range headings,
  but the line is what a reader on GitHub, or in an editor, navigates by.
- **Exclude the epic list from mdformat.** Each repository would have to
  configure it, and the next derived line to grow would need the same.
