## Goal

A repository `kiln new` creates runs pytest with `-n auto` from the start, and
its dev group carries `pytest-xdist`. It is a scaffolded default: kiln writes it
once and the repository owns it after that.

## Settled

- Owner, 2026-11-17: build the story as drafted. No drift warning, no check, no
  config key. The generated `test` and `test:coverage` tasks do not change.
- `PYTEST_ADDOPTS = "-ra --import-mode=importlib -n auto"`.
- `_DEV_GROUP` gains `"pytest-xdist>=3.8"`, in sorted place after
  `"pytest-cov>=7.1"`. `uv.lock` here locks `pytest-xdist` 3.8.0, so the floor
  test holds.
- `TASK_TOOLS` does not change: a pytest plugin is not a task tool. `TASK_TOOLS`
  is computed from `_DEV_GROUP`, so it becomes
  `tuple(distribution(entry) for entry in _DEV_GROUP if not entry.startswith("pytest-xdist"))`
  or an equivalent, and keeps every name it had.
- Tests are named for behaviour, `test_<subject>_<behaviour>`, with no spec ID
  in a name, docstring or comment. The story page's `test_s17_3_8_…` names are
  replaced by the names below.
