Every repository kiln generates parks its ideas in one `docs/specs/ideas.md`. A
large idea has to go in a section below the table there, so the page grows and
the section never shows up in the nav as a page. This feature replaces
`ideas.md` with an `ideas/` folder. `ideas/index.md` is the one table, with a
row per idea. An idea the row cannot hold also gets its own page
`ideas/<idea>.md`, linked from its row. `kiln doctor` reports a leftover
`ideas.md` and any idea page the index does not link to. The nav lists the
folder as a section.

## Context

This changes the seeded docs model, so it ships in release-1. Other repositories
adopt kiln from the release-1 tag. If they adopted `ideas.md` first, each would
have to move again. [ADR-0011](../../../adr/ADR-0011.md) holds the decision and
the alternatives it rejected. The first large idea is the proposal to move
rn-forge-devops into its own repository.

#### The seeded ideas index

The content of `templates/docs/specs/ideas/index.md.j2`, ending with one
newline:

```markdown
# Ideas

Ideas not yet agreed as this repository's work. An entry takes no ID and no
state, and does not authorize starting anything. An idea that needs more than
its row has a page in this folder, named after the row and linked from its
**Idea** cell. Promoting one moves its page, or its row's summary, into a new
epic or feature and deletes both; a dropped idea's row and page are deleted
too.

[Back to the specs](../index.md)

| Idea | Summary | Source |
| -- | -- | -- |
```

**Do not:** add a config key or a CLI flag. Do not require `ideas/index.md` to
exist. Do not seed an example idea page. Do not add a metadata table, an ID or a
state to idea pages, or give them a template file. Do not move or migrate a file
in another repository's tree. Do not change `work.py` or the board, epic list or
Scope regions. Do not edit E13's `design.md` or any closed story.
