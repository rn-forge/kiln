## S6.1.1 — Regenerate pykit's skeleton as `python-lib`

**Status:** planned

`kiln new pykit-fresh --archetype python-lib --docs mkdocs`; set
`[python] packages`; move `packages/`, `docs/`, the `mkdocs.yml` body and the
root workspace tables in; `extra_refs` for anything the generated matrix does
not cover; delete `_package-ci.yml`. Package source is untouched — pykit is kept
as-is (package source, tests, docs, plans); only the repo *skeleton* is
regenerated.

pykit takes `rn-forge-kiln` in its dev group like every generated repo, and sets
`[tool.uv] override-dependencies` naming every pykit member kiln reaches, so
kiln resolves to the workspace copies ([ADR-0010](../../../adr/ADR-0010.md); the
spike on
[S4.1.4](../E4-generator/F4.1-checks-by-module.md#s414-the-ci-shape-is-decided)).

**Acceptance:**

- pykit's config records `python-lib`, and `[python] packages` names every
  directory under `packages/`.
- Nothing under `packages/*/src` or `packages/*/tests` differs from the last
  commit before the replacement.
- `_package-ci.yml` is gone. Each of its steps is either in the generated matrix
  or an `extra_refs` entry, and the mapping is recorded on this story.
- pykit's `uv.lock` records `rn-forge-kiln`, and `rn-forge-tooling` there is the
  editable workspace member.
- In pykit, `task validate`, `lint-imports` and `kiln doctor` pass, and CI
  passes on the branch (run linked here).

## Acceptance

```bash
set -euo pipefail
: "${BASE:?set BASE to pykit's last commit before the replacement}"
cd rn-forge/pykit
rg -q '^archetype = "python-lib"' .rn-forge/kiln/config.toml                          # S6.1.1
git diff --quiet "$BASE" -- 'packages/*/src' 'packages/*/tests'                        # S6.1.1: source untouched
test ! -e .github/workflows/_package-ci.yml                                           # S6.1.1
task validate                                                                         # S6.1.1
uv run lint-imports                                                                   # S6.1.1
rg -q '^name = "rn-forge-kiln"$' uv.lock                                              # S6.1.1
rg -A2 '^name = "rn-forge-tooling"$' uv.lock | rg -q 'editable = "packages/rn-forge-tooling"'  # S6.1.1
uv run kiln doctor                                                                    # S6.1.1
```

Not scriptable: the `_package-ci.yml` step mapping and the linked CI run.
