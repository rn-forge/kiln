# S20.1.3 — The standard and the reference say tools add blocks only

Brief for
[S20.1.3](../F20.1-blocks-only.md#s2013-the-standard-and-the-reference-say-tools-add-blocks-only),

## Goal

The rendered standard, kiln's reference and the docs rules describe `AGENTS.md`
and `CLAUDE.md` as owner files. kiln adds one block to `AGENTS.md`, agentkit
adds its own blocks, and no tool owns either body.
