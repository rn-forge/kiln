# S18.9.2 — The python and node scaffolds

Brief for
[S18.9.2](../F18.9-large-files-split.md#s1892-the-python-and-node-scaffolds), at
`fef6689`. The feature page's line numbers are stale: find each named function
by name. Paths are under `src/rn_forge/kiln/modules/`.

## Goal

Split the python and node scaffolds so each unit does one job. No function in
`modules/python/` or `modules/node/` is over 60 lines. No rendered file,
finding, message or exit code changes.

## Settled

- **`python/scaffold.py` (595 lines) splits** into `python/uv_init.py`
  (`_uv_init`, `uv_gitignore` and the sample test) and `python/pyproject.py`
  (the pyproject reconcile: `_reconcile_pyprojects`, `_reconcile_pyproject`,
  `_reconcile`, `_join_workspace`, `_tidy`, `_multiline_lists` and the TOML
  array helpers). `scaffold.py` keeps the public steps (`scaffold_backend`,
  `reconcile_backend`, `add_package`, `package_preflight`, `declared_modules`,
  `without_members`) and imports the rest. Every public name keeps its current
  import path, `rn_forge.kiln.modules.python.scaffold.<name>`, because tests
  and `commands/` patch them there. A private name a test reads (for example
  `python_scaffold._tidy` in `tests/modules/python/test_scaffold.py`) is
  imported from its new module, and that is the only allowed test edit.
- **`_reconcile_pyproject`** builds one `_Target(name, module, role)` per
  pyproject, where `role` covers root, workspace root and member. `_reconcile`
  takes that target in place of its keyword arguments, and is at most 60
  lines.
- **`python/checks/rn_forge_deps.py` `check`** (63 lines) splits into helpers,
  so it is at most 60 lines. Its findings and their order stay exactly as they
  are.
- **`node/scaffold.py` `reconcile_node`** (74 lines) splits into
  `_fold_workspace`, `_stamp_root` and `_place_app`, called in today's order.
  Its long docstring becomes the contract: what it reads, what it writes, what
  it raises.
- **References go.** ADR, story and decision references, and design rationale,
  leave the docstrings and comments of `node/__init__.py`, the top of
  `python/scaffold.py` and every file this story touches.
