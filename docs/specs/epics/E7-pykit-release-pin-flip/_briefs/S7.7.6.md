# S7.7.6 — An installed tool reads its CLI declaration from its package

Brief for
[S7.7.6](../F7.7-kiln-installs-as-a-tool.md#s776-an-installed-tool-reads-its-cli-declaration-from-its-package),
at `4af0d5e`.

## Goal

kiln renders `src/<package path>/cli.toml`, a managed file holding the config's
`[cli]` and `[lifecycle]` tables, for every repository with lifecycle verbs. The
seeded `main.py` of a new `python-tool` reads it from the package, so an
installed tool starts. kiln's own hand-kept `src/rn_forge/kiln/cli.toml` becomes
the rendered file.

## Settled

- **When:** `config.lifecycle` is true (`KilnConfig.lifecycle`,
  `src/rn_forge/kiln/config.py:61`; `python-tool` always). Otherwise nothing
  is rendered.

- **Path:** `"src/" + config.module.replace(".", "/") + "/cli.toml"`. For kiln
  that is `src/rn_forge/kiln/cli.toml`; for the `python-tool` cell,
  `src/python_tool/cli.toml`.

- **Content:** an `Artifact(path, ArtifactKind.MANAGED, text)` (the shape
  `modules/docs/artifacts.py:132` uses), where `text` is the line
  `# Generated by kiln {__version__} from .rn-forge/kiln/config.toml — do not edit; run 'kiln apply'`
  (the header every managed file carries; copy it exactly from
  `modules/cicd/templates/sonar-project.properties.j2:1`), then
  `DocumentUtils.dumps({"cli": cli, "lifecycle": lifecycle}, ConfigFormat.TOML, multiline_arrays=True)`.
  `cli` and `lifecycle` are the config document's `cli` and `lifecycle`
  tables (`schema.py:117-121`), omitted from the mapping when `None`. The
  output must pass taplo (`task lint`) unchanged; if `dumps` output is not
  taplo-stable, stop and report rather than hand-formatting.

- **Where:** `src/rn_forge/kiln/modules/python/artifacts.py`, a function
  `_cli_declaration(config) -> list[Artifact]` added to what `render` returns.
  Update `render`'s docstring and the module docstring.

- **The generated `main.py`**
  (`modules/python/templates/starter/main_tool.py.j2`) becomes kiln's
  `src/rn_forge/kiln/main.py` shape:

    ```python
    from importlib.resources import files

    from rn_forge.commons.fs.documents import DocumentUtils
    from rn_forge.tooling.cli.lifecycle import build_tool_app

    SURFACE = DocumentUtils.read(files("{{ package }}").joinpath("cli.toml"))

    app = build_tool_app(SURFACE)
    ```

    Its docstring says the declaration is read from the packaged `cli.toml`, which
    kiln renders from `.rn-forge/kiln/config.toml`. `main_app.py.j2`
    (python-app, no lifecycle) is unchanged.

- **`commands.py.j2`'s docstring** (line 5–6): the `[cli]` table "in
  `.rn-forge/kiln/config.toml`, rendered into the packaged `cli.toml`".

- **kiln's own file:** after the change, `task kiln:apply` must render
  `src/rn_forge/kiln/cli.toml`. If apply refuses because the hand-kept file
  exists, run `task kiln:apply -- --force src/rn_forge/kiln/cli.toml`. The
  file's hand-written comment block goes; the rendered header replaces it.

- **Delete** `test_packaged_surface_matches_repo_config` and
  `test_packaged_lifecycle_matches_repo_config` from
  `tests/commands/test_cli_surface.py`, and update that module's docstring
  (its premise, two hand copies, is gone). Keep every other test there.

- **Ownership:** the new file is generated, so `task lint`'s drift check owns it
  like any other managed file. Nothing to register beyond returning the
  artifact, unless the build shows otherwise; if a registry or catalog test
  lists every managed path (e.g. `tests/modules/core/test_catalog.py`), add
  the new path there.

- Tests are named for behaviour, `test_<subject>_<behaviour>`, with no spec ID
  in a name, docstring or comment.
