A configured check, on by default (`node-lib` also gets `pnpm audit`, a standard
check, in S15.2.4): `task` fails when a dependency's licence matches the deny
list (default `GPL`, `GPL-*`, `AGPL`, `AGPL-*`, `UNKNOWN`) and the package is
not in the ignore list. It is a step of `task lint`, so `validate` runs it, with
no job of its own. Python uses `pip-licenses`; `node-lib` uses `pnpm licenses`,
which understands pnpm's layout. Both feed one matcher, `kiln-devops licenses`.

**What the producers emit.** `pip-licenses` defaults to `--from=mixed`, which
prefers a package's Trove classifiers to its `License` field. So a GPL package
usually reports `GNU General Public License v3 (GPLv3)`, not `GPL-3.0-only`, and
several classifiers come joined by `; `. The `License` field and pnpm's keys are
free text too, though usually SPDX. The deny list is written in SPDX terms, so
the matcher normalises each value to an SPDX-style identifier before matching. A
value it cannot normalise is matched as written.

   `fmt="pnpm"`, `deny=["UNKNOWN"]` returns `["c 3.0.0 Unknown"]`.

1. `test_s15_2_1_3_matching_is_case_insensitive_and_whole_string`: `LGPL-3.0`
   and `GNU Lesser General Public License v3 (LGPLv3)` are not matched by
   `GPL-*`; `gpl-2.0-only` and `GNU General Public License v2 (GPLv2)` are.
   The bare family `GPL` is matched by the default deny list, which names it
   (`GPL` and `GPL-*`), and not by `GPL-*` alone.

1. `test_s15_2_1_4_multiple_licences`: a pip-licenses licence
   `MIT License; GNU General Public License v3 (GPLv3)` is an offender, and
   each `;`-separated part is normalised and matched alone.

1. `test_s15_2_1_5_ignore`: a package named in `ignore` is never an offender.

1. `test_s15_2_1_6_cli`:
   `main(["licenses", "--format", "pip-licenses", "--deny", "GPL-*"])` with
   the offender input on stdin returns `1` and prints the offender line to
   stderr; with a clean input it returns `0`; with `not json` it returns `2`.

1. `test_s15_2_1_7_real_pip_licenses_output`: the producer's actual output, not
   a hand-written fixture. Write two distributions into `tmp_path`, each a
   `<name>-1.0.dist-info/METADATA`: `gplpkg`, whose only licence is the
   classifier
   `License :: OSI Approved :: GNU General Public License v3 (GPLv3)`, and
   `mitpkg`, with `License: MIT` and no classifier. Run
   `sys.executable -m piplicenses --format=json --packages gplpkg mitpkg` with
   `PYTHONPATH=tmp_path`, and pipe its stdout into `licenses.run` with the
   default deny list. The result is exactly `gplpkg`'s line. Skip when
   `piplicenses` cannot be imported, which holds until S15.2.2 adds it to the
   dev group.

**Build:** new `src/rn_forge/kiln/devops/licenses.py` with `run`, and a
`licenses` subparser in `devops/cli.py` (`--format {pip-licenses,pnpm}`
required, `--deny` and `--ignore` repeatable, JSON on stdin). `normalise` runs
first: the GNU classifier names map through a table, one row per classifier in
the test above. Free-text short forms match
`^(A|L)?GPL[ -]?v?(\d)(\.0)?(\+| or later)?$` (case-insensitive) and become
`<family>-<n>.0`, plus `-or-later` for `+`; `GPL`, `AGPL` and `LGPL` alone stay
the bare family; `UNKNOWN`, `Unknown` and empty become `UNKNOWN`; every other
value passes through unchanged. Then match with `fnmatch.fnmatchcase` on
`casefold()`ed strings. An offender line is `<name> <version> <licence>`; a pnpm
package with several versions yields one line each. `main` follows the other
subcommands' error style (`kiln-devops: <message>` on stderr).
