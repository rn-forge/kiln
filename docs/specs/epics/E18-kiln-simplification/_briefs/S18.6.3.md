# S18.6.3 — Logic the commands borrowed goes back to its owner

Brief for
[S18.6.3](../F18.6-commands-package.md#s1863-logic-the-commands-borrowed-goes-back-to-its-owner),
at `503ffa5`. Line references are at that commit.

## Goal

Move the module logic still held by `new`, `generate` and `config` back to the
modules that own it, so `commands/` imports neither `subprocess` nor
`StateStore`. No command's flags, output, exit code or message changes.

## Settled

- **S18.6.2 already moved three names verbatim**: `cycle.record_scaffolded`
  (`src/rn_forge/kiln/modules/core/cycle.py:271-301`), and
  `python_scaffold.declared_modules` and `python_scaffold.without_members`
  (`src/rn_forge/kiln/modules/python/scaffold.py`). This story rewrites
  `record_scaffolded`; the other two stay as they are.
- **The command-level `add_package` stays in `commands/generate.py`** (lead's
  ruling, 2026-11-17). The story moves it to `modules/python/scaffold.py`, but
  it calls `docs_scaffold.add_package`, `docs_generator.generate` and
  `cycle.apply`, and `.importlinter`'s `concern-modules-are-independent`
  contract forbids `rn_forge.kiln.modules.python` from importing
  `rn_forge.kiln.modules.docs`. Composing modules is the commands' job. Only
  `_package_preflight` and `_PACKAGE_NAME` move.
- **`cycle.preview(root, config) -> list[generation.Change]`** replaces both row
  builders. It collects every artifact of
  `ConfigManager().modules_for(config)` (no starter filter: that is F18.10's
  defect), loads the entries of `root / umbrella.STATE_PATH` with today's
  `StateStore` arguments (an empty mapping when the file does not exist), and
  returns `classify(root, artifacts, entries).changes`. The callers keep
  today's selection: `new` shows every change; `config-update` and
  `config-upgrade` drop `UNCHANGED` and `SKIP`, as `_config_change_rows` does
  now. `new` builds its rows with `output.change_rows`, so
  `output.artifact_rows` goes.
- **The `cli` and `lifecycle` defaults move to
  `src/rn_forge/kiln/modules/python/starter.py`** as
  `starter_flags(archetype: str, name: str, package: str) -> dict[str, object]`,
  added to its `__all__`. It returns `{"cli": {...}}` for `python-tool` and
  `python-app`, plus `"lifecycle"` for `python-tool`, with today's values from
  `commands/new.py:196-207`, and `{}` for any other archetype. `new` sets each
  returned key with `DictUtils.set`.

## Current behaviour

- `cycle.record_scaffolded` (`cycle.py:271-301`) calls `subprocess.run` for
  `git -C <dir> ls-files --others --exclude-standard -z`, writes
  `directory / ".rn-forge" / "kiln" / "state.json"` by literal, and sets
  `state["metadata"]["scaffolded"]` by literal. `cycle.SCAFFOLDED_KEY`
  (`cycle.py:46`) and `umbrella.STATE_PATH` (`umbrella.py:24`) already name
  both.
- `commands/generate.py:90-115`: `_package_preflight` validates and returns
  `f"https://github.com/{config.owner}/{config.name}"`; `_PACKAGE_NAME` is the
  name pattern. `python_scaffold.add_package(root, config, name, remote)`
  (`scaffold.py:178`) splits that URL back into owner and repo (`:202-203`).
- `commands/new.py:139-211` `_resolve_config` takes `owner_error` from its one
  caller (`:85-86`) and parses `Source` twice (`:164`, `:210`). It returns
  `(manager, resolution)`; `new` uses the manager only for `_preview_rows`.
- `commands/new.py:214-225` `_preview_rows` classifies each artifact against no
  state (`output.artifact_rows`). `commands/config.py:92-109`
  `_config_change_rows` classifies against `state.json` through
  `cycle.classify` and drops `UNCHANGED`/`SKIP`; it is the only `StateStore`
  user under `commands/`.
- `tests/modules/core/test_derived.py:201-206` reads `commands/config.py` and
  asserts `_config_change_rows` calls `cycle.classify(`.

## Change

1. Write the tests (below) and show them failing as stated.
1. `cycle.record_scaffolded`: list the files with
   `Process.execute("git-ls-files", "git", "-C", str(directory), "ls-files", "--others", "--exclude-standard", "-z").stdout`,
   read and write `directory / umbrella.STATE_PATH`, and key on
   `SCAFFOLDED_KEY`. Drop `import subprocess` from `cycle.py` if nothing else
   uses it. Confirm `Process.stdout` is a `str` before relying on it.
1. `python/scaffold.py`: add
   `package_preflight(root, config, name, module=None) -> None` (today's
   `_package_preflight` without the return) and `_PACKAGE_NAME`; `add_package`
   becomes `add_package(root, config, name, owner, repo)` and builds
   `remote = f"https://github.com/{owner}/{repo}"` itself. Update its
   docstring's `Args`. `commands/generate.add_package` calls
   `python_scaffold.package_preflight(root, config, name, module)` and then
   `python_scaffold.add_package(root, config, name, config.owner, config.name)`.
   Remove the moved names and the now-unused imports from `generate.py`.
1. `commands/new.py` `_resolve_config`: delete `owner_error`; raise
   `AppException("new.owner-required: pass --owner <owner> or set repository.owner in --config")`
   in place. Parse `source = Source.parse(config) if config else None` once,
   and use it for `fetch(source, Path.cwd())` and
   `manager.resolve(..., source=source)`. Replace `:195-207` with
   `package = module or root_package(name)` and a loop over
   `python_starter.starter_flags(archetype, name, package)`. If the manager is
   no longer needed by `new`, return only the `Resolution`.
1. `cycle.preview` as settled; add it to `cycle.py`'s `__all__`. In `new.py`,
   `rows = output.change_rows(cycle.preview(directory, resolved))` and delete
   `_preview_rows`. In `config.py`, build `rows` from
   `cycle.preview(root, resolution.config)` minus `UNCHANGED`/`SKIP`, and
   delete `_config_change_rows` and its `StateStore`/`StateEntry` imports.
   Delete `output.artifact_rows` and anything only it used.

    - `tests/modules/python/test_scaffold.py:499`:
      `add_package(root, config, name, "acme", "demo-lib")`.
    - `tests/modules/core/test_derived.py:201-206`: read `cycle.py` instead, find
