A configured check, off by default, for public repositories only: a separate
kiln workflow, `.github/workflows/scorecard.yml`, on a schedule, with
`security-events: write`. It reports and does not gate, so it is not in `ci-ok`.

## S15.6.1 — kiln renders `scorecard.yml`

**State:** New

**Build — tests first,** in `tests/modules/cicd/test_artifacts.py` and
`tests/modules/cicd/test_pins.py`:

1. `test_s15_6_1_1_absent_by_default`: no `scorecard.yml` in any archetype's
   render.
1. `test_s15_6_1_2_on`: with `[ci.checks] scorecard = true`, the render has
   `.github/workflows/scorecard.yml` with `on: schedule`
   (`cron: '17 4 * * 1'`) and `workflow_dispatch`, one job `analysis` with
   `permissions:` `contents: read`, `actions: read`, `id-token: write`,
   `security-events: write`, steps checkout (`persist-credentials: false`),
   `ossf/scorecard-action` (`results_file: results.sarif`,
   `results_format: sarif`, `publish_results: true`) and
   `github/codeql-action/upload-sarif` (`sarif_file: results.sarif`).
1. `test_s15_6_1_3_not_gating`: `ci.yml`'s `ci-ok` does not need `scorecard`.
1. `test_s15_6_1_4_pins`: `load_pins()` has `scorecard` and `upload-sarif`
   tables with `uses`, `sha` and `version`, and `scorecard.yml` passes the
   `ci-pins` check.
1. `test_s15_6_1_5_generated_job_name`: a `[[ci.jobs]]` named `scorecard` is
   refused.

**Build:** `cicd/templates/scorecard.yml.j2`; `cicd/artifacts.py` renders it
when `registry.enabled` says so; two `pins.toml` tables, SHAs resolved from the
actions' latest release tags with
`gh api repos/<owner>/<repo>/git/ref/tags/<tag>`. The `registry` row's
`key_note` says "public repositories only". The workflow needs no `task` verb:
it runs one action, which `ci.entrypoint` allows.

**Acceptance:**

- The five tests pass, and `task validate` passes (`zizmor` and `actionlint`
  accept the rendered file).
- `task self:golden:compare BASE=HEAD`: no cell changes.

Not scriptable: on a public repository with the check on, the workflow runs and
its results appear under Code scanning.

**Closing step:** move this feature's rows (Scorecard) from
[design.md](design.md) to [ci.md](../../../architecture/ci.md).
