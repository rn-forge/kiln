E7's scope items 1 and 3: tag an `rn-forge-kiln` release, then each repository
moves its kiln pin with `kiln upgrade` ([ADR-0006](../../../adr/ADR-0006.md))
and runs `kiln config upgrade --apply`. Added 2026-10-17 by S6.1.14, so that
E7's `Active` state has a feature to agree with. Stories are written at the
release-1 cut.

Since [F7.4](F7.4-kiln-runs-beside-the-repository.md), a repository's kiln pin
is `[kiln] ref` in `.rn-forge/kiln/config.toml`, not a dev dependency. "Moving
the pin" therefore means:

1. set that ref to the new tag;
1. run `kiln apply`, which re-renders the `KILN` var in `tasks/kiln.yml` and
   `tasks/docs.yml`.

The cut also sets `archetypes.KILN_REF` from `feature/v1` to `v<version>`, so
`kiln new` pins the release.
