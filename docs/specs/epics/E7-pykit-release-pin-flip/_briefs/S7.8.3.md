# S7.8.3 — `kiln doctor` warns when a floor is below the pin table

## Goal

`rn-forge-deps` warns, with `deps.behind`, when a repository's rn-forge floor is
below kiln's pin table. The warning names `task kiln:upgrade`.

## Settled

All settled by the owner on 2026-11-18.

- **The check.** Add
  `_check_behind(label: str, document: dict[str, object], members: frozenset[str]) -> list[Finding]`
  to `src/rn_forge/kiln/modules/python/checks/rn_forge_deps.py`. Call it
  last in `_check_document`'s list (line 357). Pass `members` through:
  `_check_document` already has it.

- **What it checks.** For each `requirement` in `every_dependency(document)`,
  let `name = distribution(requirement)`. Skip the requirement unless all of
  these hold:

    - `governed(name)` is true.
    - `name` is not in `members`.
    - `name` is a key of `archetypes.RN_FORGE_TAGS`.
    - `archetypes.floor(requirement)` is not `None`. (S7.8.1 added `floor` and
      `version_key`.)

    The table version is `archetypes.RN_FORGE_TAGS[name].rpartition("-v")[2]`.
    When `version_key(floor) < version_key(table)`, add one finding.

- **The finding:**

    ```python
    Finding(
        f"{CODE}.behind",
        Severity.WARNING,
        f"`{name}` has floor {floor}, below kiln's pin table ({table}) — "
        f"run `task kiln:upgrade` to move it",
        path=label,
    )
    ```

- **No error, by design.** A warning does not fail `kiln doctor`
  (`commands/doctor.py:105` raises only on errors).

- **Update the module docstring** (lines 1-24): add a rule after rule 4, "**At
  the pin table.** A floor below kiln's pin table is a warning: the repository
  has not taken this kiln's pykit floors." Keep the numbering consistent.

- **Docs.** In `docs/reference/standard-repo.md`'s check-code table, add a row
  after `deps.no-index` (line 406):
  `| `deps.behind`| warning: an rn-forge floor is below kiln's pin table;`task
  kiln:upgrade` moves it |`. If
  `src/rn_forge/kiln/modules/instructions/templates/standard.md.j2` has the
  same table (`rg -n 'deps.no-ceiling'` on it), add the row there too.

- **Test names** describe behaviour, with no spec ID.
