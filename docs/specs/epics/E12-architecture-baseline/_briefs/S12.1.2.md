# S12.1.2 — The `docs` module renders the Python records

Brief for
[S12.1.2](../F12.1-python-baseline.md#s1212-the-docs-module-renders-the-python-records),

## Goal

With `docs.profile = "mkdocs"`, the `docs` module renders kiln's architecture
records into `docs/adr/kiln/` and a kiln block into `docs/adr/index.md`, for
every Python cell, and nothing for `node-lib`.
