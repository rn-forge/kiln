## S5.3.1 — Ship three cells

**Status:** planned

Shipped cells: `python-web-api` + fastapi; `python-web-app` + django + angular;
`python-web-app` + fastapi + angular — the last is the shape the
[intellibuild plan](../../../plans/intellibuild.md) builds on, though
intellibuild does not gate this feature. `react`, `svelte` and `python-web-api`
\+ django stay `untested = true`.

**Acceptance:**

- `task self:golden:render` renders the three web cells alongside the Python
  cells, and `task self:golden:validate` passes for each.
- `kiln new` with `react`, with `svelte`, or with
  `python-web-api --framework django` exits non-zero without the override,
  naming the value.
- The owner's approval of the rendered web cells is recorded on this story.
- The open question is answered, and the shipped list above matches the answer.

## Acceptance

```bash
set -euo pipefail
fails_with() { local out rc=0; out=$("${@:2}" 2>&1) || rc=$?; [ "$rc" -ne 0 ] && grep -qF -- "$1" <<<"$out"; }
cd rn-forge/kiln
task self:golden:render                                                               # S5.3.1
task self:golden:validate                                                             # S5.3.1
s=$(mktemp -d)
fails_with react uv run kiln new "$s/r" --archetype python-web-app --framework fastapi --frontend react --docs none --yes </dev/null    # S5.3.1
fails_with svelte uv run kiln new "$s/s" --archetype python-web-app --framework fastapi --frontend svelte --docs none --yes </dev/null  # S5.3.1
fails_with django uv run kiln new "$s/d" --archetype python-web-api --framework django --docs none --yes </dev/null                    # S5.3.1
```

Not scriptable: the owner's approval and the answered question.
