# F5.2 — `kiln new` end to end for the web archetypes

Epic: [E5](index.md) · **Depends on:**
[F5.1](F5.1-web-library-sets-and-modules.md); S5.2.1 on S5.2.2, whose fixture is
the reconcile's test input; S5.2.3 on [F5.3](F5.3-shipped-web-cells.md)'s open
question

**Build a story by the [board's procedure](../../index.md#building-a-story).**
The frontend scaffolder is the one part of kiln that runs someone else's
generator, so it is built the way the goldens were: capture its real output
once, test the reconcile offline against that capture, then wire the live run.

## S5.2.2 — Capture the frontend scaffolder's output

**Status:** planned

taskkit's `tests/fixtures/repos/*` are *detection* inputs — a `pyproject.toml`
and a `package.json`, no Nx workspace — and cannot feed a reconcile. They are
not moved; they retire with taskkit
([F6.2](../E6-rebuild-the-repos/F6.2-retire-taskkit.md)). Instead, one real
scaffold is captured.

**Build:**

- Run the pinned scaffolder once into a scratch directory:

    ```bash
    pnpm dlx create-nx-workspace@<NX_VERSION> ws --preset=angular-monorepo --appName=web \
      --style=scss --bundler=esbuild --ssr=false --e2eTestRunner=none --unitTestRunner=vitest \
      --packageManager=pnpm --nxCloud=skip --ci=skip --interactive=false --skipGit
    ```

    `<NX_VERSION>` is the current `create-nx-workspace` release on the day of the
    capture. If that release rejects a flag above, drop or rename it — and the
    command that actually ran, verbatim, is the one recorded. The preset must
    produce the app under `apps/web`, an eslint config and a unit-test runner,
    so that `web:lint`, `web:test` and `web:build` all have a target.

- Commit the output as `tests/fixtures/scaffold/nx-angular/`, without
  `node_modules/`, `.git/` or `.nx/`, keeping `pnpm-lock.yaml`. Write the
  exact command and the version to
  `tests/fixtures/scaffold/nx-angular/COMMAND.md`, and set
  `NX_VERSION = "<version>"` in `modules/python/frontend.py`.

- `tests/fixtures/**` is already excluded from ruff, pyright and pytest
  collection; check `.mdformat.toml` excludes it too, and add it if not.

**Acceptance:**

- `tests/fixtures/scaffold/nx-angular/` exists, holds `apps/web/project.json`,
  `nx.json`, `package.json`, `pnpm-workspace.yaml` and `pnpm-lock.yaml`, and
  holds no `node_modules`.
- `COMMAND.md` records the command, the version and the date; `NX_VERSION`
  equals the recorded version.
- `task validate` passes with the fixture in the tree.

## S5.2.1 — Scaffold the frontend

**Status:** planned

`kiln new` end to end: the frontend scaffolder runs into a scratch directory,
and the reconcile moves its output into the repo at `web_dir`.

**Build:**

- `modules/python/frontend.py` with `scaffold_frontend(root, config) -> None`
  and `reconcile_frontend(root, workspace, config) -> None`.
  `scaffold_frontend` returns at once unless
  `config.archetype == "python-web-app"`; otherwise it runs the recorded
  `COMMAND.md` line through `Process.execute` (the same wrapper `uv init`
  uses) with `ws` in a `tempfile.TemporaryDirectory`, then calls
  `reconcile_frontend` on `ws`. `frontend` values other than `angular` never
  reach here: `kiln new` refuses them as untested.
- `reconcile_frontend` moves every top-level entry of `workspace` into `root`
  except `.git`, `node_modules` and `.nx`; if the scaffolder's app directory
  (`apps/web`) differs from `config.web_dir`, it renames it and rewrites the
  path in `apps/web/project.json`'s `sourceRoot` and `root` and in
  `tsconfig.base.json`'s `paths`, and nothing else. A `.gitignore` the
  scaffolder wrote is appended to the repo's `.gitignore` body (created if
  absent), *before* apply inserts kiln's block. A root file that already
  exists in `root` (`README.md`, `.editorconfig`, `.prettierrc`) is a
  conflict: the reconcile raises `AppException` naming it, since two owners
  never write one file.
- `python`'s `scaffold` calls `scaffold_frontend` after the uv steps;
  `kiln new`'s order stays python → docs → instructions → apply.
- kiln templates nothing the scaffolder wrote: no artifact path lies under
  `web_dir`, and none names a root file the scaffolder owns.

**Tests:** `tests/modules/python/test_frontend.py`, `test_s5_2_1_…`. The
reconcile tests copy `tests/fixtures/scaffold/nx-angular/` into a temporary `ws`
and reconcile into a temporary root that already holds a `python` scaffold; no
test runs `pnpm`.

**Acceptance:**

- After `reconcile_frontend` over the fixture: `root/nx.json`,
  `root/package.json` and `root/<web_dir>/project.json` exist; `root/ws` does
  not; the fixture's `.gitignore` lines are in `root/.gitignore`; with
  `web_dir = "apps/frontend"` the app is at that path and `project.json`'s
  `root` says so.
- The reconcile refuses a root that already holds `README.md`, naming it.
- `kiln new … --archetype python-web-app --framework fastapi --frontend angular --yes`,
  with stdin closed, runs the scaffolder and leaves `pnpm-lock.yaml` at the
  root. In the result, `uv sync`, `pnpm install --frozen-lockfile` and
  `task validate` pass, and `kiln doctor` exits 0. This is the feature block
  below, run by hand and recorded on this story with the date.
- No key in `kiln new --json`'s `.artifacts[]` starts with `web_dir`, nor equals
  a root file the fixture holds.

## S5.2.3 — The django scaffold

**Status:** planned · **Blocked on:** [F5.3](F5.3-shipped-web-cells.md)'s open
question — not built while `django` is `untested`

`framework = "django"` adds `manage.py` and a project package at `api_dir`
([ADR-0005](../../../adr/ADR-0005.md)). `django-admin startproject` needs Django
installed, so it runs after the member's `uv sync`, which `kiln new` does not do
today; the order and the reconcile are this story's design when it opens.

**Acceptance:** written when the story opens.

## Acceptance

```bash
set -euo pipefail
cd rn-forge/kiln
kiln_dir=$PWD
test -f tests/fixtures/scaffold/nx-angular/apps/web/project.json                     # S5.2.2
test -f tests/fixtures/scaffold/nx-angular/COMMAND.md                                 # S5.2.2
test ! -e tests/fixtures/scaffold/nx-angular/node_modules                             # S5.2.2
task test                                                                             # S5.2.1: the reconcile over the fixture
s=$(mktemp -d)
uv run kiln new "$s/web" --archetype python-web-app --framework fastapi --frontend angular --docs mkdocs --yes --json </dev/null >"$s/new.json"  # S5.2.1
jq -e --arg w "apps/web" '[.artifacts[].key | select(startswith($w))] | length == 0' "$s/new.json"  # S5.2.1: nothing under web_dir
(cd "$s/web" && uv sync && pnpm install --frozen-lockfile && task validate && uv run --project "$kiln_dir" kiln doctor)  # S5.2.1
```
