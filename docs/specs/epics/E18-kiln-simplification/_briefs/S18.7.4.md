## Goal

Delete the code nothing in `src/` calls, trim `__all__` lists to their real
callers, and collapse the small duplications the story names. No rendered file
changes.

## Settled

**The deletion rule** (lead's ruling, 2026-11-17). Before deleting a name, grep
`src/` and `tests/` for it.

- A name with a caller in `src/` is not dead: leave it, and record it in
  `## Result`. At `e5e47ca` that already holds for
  `modules/core/checks/generated.py` `digest` (called at `:127`), for
  `modules/docs/work.py` `_title` (called at `:232`), and for
  `config.web_dir or SCAFFOLD_APP_DIR` in `modules/node/scaffold.py:171` and
  `modules/node/starter.py:48`, since a `node-lib` config has no `web_dir`.
- A name only tests call is deleted. A test that exercises its behaviour is
  rewritten through the public function that reaches it. A test that can only
  call the deleted name directly is deleted with it, and listed in `## Result`
  with what still covers that behaviour.
- A fallback is dead only when every caller provably passes a value. Prove it
  from the types or the call sites, and say how in `## Result`; otherwise
  leave it.
