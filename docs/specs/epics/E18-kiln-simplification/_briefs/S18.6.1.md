# S18.6.1 — One output module

Brief for [S18.6.1](../F18.6-commands-package.md#s1861-one-output-module), at
`e7ad041`. Line references are to `src/rn_forge/kiln/commands.py` at that commit
unless they name another file.

## Goal

Every command sets its JSON mode, prints JSON-or-text, builds artifact rows and
reports findings through one module, `src/rn_forge/kiln/commands/output.py`. No
command's flags, output, exit code or message changes.

## Settled

- **`commands.py` becomes `commands/__init__.py` first** (lead's ruling,
  2026-11-17). The story puts `output.py` under `commands/` while the commands
  are still one file, and a `commands/` package cannot sit beside a
  `commands.py` module. So step 1 is
  `git mv src/rn_forge/kiln/commands.py src/rn_forge/kiln/commands/__init__.py`,
  with no other edit. Every `cli.toml` target
  `rn_forge.kiln.commands:<name>` keeps resolving, so neither
  `src/rn_forge/kiln/cli.toml` nor `.rn-forge/kiln/config.toml` changes.
  S18.6.2 splits `__init__.py` into modules.
- **`emit` takes a text printer, not lines** (lead's ruling). The text forms
  differ by command: `console.info` rows (`apply`, `config-*`),
  `console.print` with `markup=False` (`diff`, `prompt`), a table
  (`doctor --all`), plain `console.print` (`version`). A list of lines would
  force one printer and change output. So `emit(payload, text)` prints
  `payload` with `console.json` when `console.mode is OutputMode.JSON`, else
  calls `text()`.
- **The mode check reads `console.mode`**, never the `json` flag, because the
  root `--json` flag also sets it. `version` (`:706-714`) is the one command
  that calls `set_mode` after other work; `use_json` there keeps today's
  behaviour.
- **Messages are kept byte for byte.** `doctor` (one path) raises
  `"{} check(s) failed in {}"`; `docs_generate` raises
  `"{} finding(s) in {}"`; `_fail_on_errors` raises
  `"{} check(s) failed in {}"`. `doctor --all` keeps its own summary
  (`:188-193`, "across {} repo(s)") and does not use `report_findings`.

- Row builders: `_preview_rows` (`:776-792`, classifies each artifact against no

  `{key, path, kind, action}` dict. `_finding_json` is at `:102-108`; `_emit`

- No module outside `commands.py` under `src/` mentions `set_mode` or
  `OutputMode`.
- Tests that read `commands.py` by path:
  `tests/modules/core/test_derived.py:201` (reads the file text and finds
  `def _config_change_rows`).

## Change

1. Write the test (below) and show it failing.
1. `git mv src/rn_forge/kiln/commands.py src/rn_forge/kiln/commands/__init__.py`.
   In `tests/modules/core/test_derived.py:201`, the path becomes
   `SRC / "rn_forge" / "kiln" / "commands" / "__init__.py"`; that is the only
   edit to an existing test.
1. New `src/rn_forge/kiln/commands/output.py`, with a module docstring and
   `__all__`, holding:
    - `use_json(flag: bool) -> None`: `console.set_mode(OutputMode.JSON)` when
      *flag*.
    - `emit(payload: Mapping[str, object], text: Callable[[], None]) -> None`, as
      settled.
    - `emit_rows(payload, rows)`: today's `_emit` (`:928-934`), built on `emit`.
    - `finding_json(finding)`: today's `_finding_json`.
    - `report_findings(findings, where, what="check(s) failed in") -> None`:
      `console.error("{}", finding)` for each, then, if any is an error,
      `raise AppException("{} " + what + " {}", len(errors), where)`.
      `docs_generate` passes `what="finding(s) in"`.
    - `change_rows(changes)` and `artifact_rows(directory, artifacts)`, sharing
      one private `_row(key, path, kind, action)` that returns the
      `{key, path, kind, action}` dict. `artifact_rows` keeps `_preview_rows`'s
      `generation.classify(directory, artifact, None)`.
1. In `commands/__init__.py`, move every command onto it:
    - each `if json: console.set_mode(OutputMode.JSON)` →
      `output.use_json(json)`;
    - each JSON-or-text branch → `output.emit(...)` with a local printer, or
      `output.emit_rows(...)`; keep early returns as they are;
    - the three findings blocks → `output.report_findings(...)`;
    - `_preview_rows` → a loop over `manager.modules_for(config)` feeding
      `output.artifact_rows`; `_change_rows` → `output.change_rows`; delete
      `_emit` and `_finding_json`. `_report` stays in `__init__.py` but uses
      `output.emit`.
    - Remove the `OutputMode` import from `__init__.py`.
    - Import it as `from rn_forge.kiln.commands import output`.
