# S20.1.1 — `kiln new` seeds no instruction-file body

Brief for
[S20.1.1](../F20.1-blocks-only.md#s2011-kiln-new-seeds-no-instruction-file-body),
at `feature/v1` after `bb7cf86`.

## Goal

`kiln new` scaffolds `README.md` only. It writes no `CLAUDE.md` and no
`AGENTS.md` body; the first apply creates `AGENTS.md` holding only the
`rn-forge kiln` block.

## Settled

- `BODIES` in `src/rn_forge/kiln/modules/instructions/scaffold.py` becomes
  `("README.md",)`. The module and function docstrings say it scaffolds
  `README.md` only.
- Delete `src/rn_forge/kiln/modules/instructions/templates/AGENTS.md.j2` and
  `src/rn_forge/kiln/modules/instructions/templates/CLAUDE.md.j2`.
- No change to `cycle.py`, `record_scaffolded` or the block artifact. The apply
  already creates an absent `AGENTS.md` from the block alone
  (`tests/modules/core/test_cycle.py` expects `AGENTS.md#rn-forge kiln` to be
  `INSERT` with no scaffold). `metadata.scaffolded` stops listing `CLAUDE.md`
  because the file no longer exists.
- A repository whose `AGENTS.md` and `CLAUDE.md` carry the old seeded bodies is
  untouched outside kiln's block by `kiln apply`. That is already true; a test
  pins it.
- `standard.md.j2` is not touched here; S20.1.3 rewrites its ownership text.
- Test names describe behaviour, with no spec IDs.

## Current behaviour

- `scaffold()` writes `README.md`, `CLAUDE.md` and `AGENTS.md` (from
  `BODIES = ("README.md", "CLAUDE.md", "AGENTS.md")`). After `kiln new`,
  `AGENTS.md` holds the seeded skeleton (Rules, Guardrails, … headings) with
  the kiln block appended, and `CLAUDE.md` is `@AGENTS.md` plus a Claude-only
  stub.
- `state.json`'s `metadata.scaffolded` lists `CLAUDE.md` and `README.md`.
- So the new tests below fail before the change: `CLAUDE.md` exists after
  `scaffold`/`kiln new`, `metadata.scaffolded` contains `CLAUDE.md`, and
  `AGENTS.md` has text outside the block.

## Change

- **Change:** `scaffold.py` as settled; delete the two templates.
- **Then:** run `task kiln:apply`. It must change no file in this repo: kiln's
  own `AGENTS.md` and `CLAUDE.md` exist, and only the block is reconciled.
- **Leave alone:** `standard.md.j2`, `docs/reference/standard-repo.md`, the docs
  module, every generated file, and every spec page except this brief's
  `## Result`.
