# S16.5.6 — A web API member has no console script

Brief for
[S16.5.6](../F16.5-rebuild-and-port.md#s1656-a-web-api-member-has-no-console-script),
at `019beea`. Line references are at that commit.

## Goal

A fresh `python-web-api` or `python-web-app` API member declares no
`[project.scripts]`, instead of uv's stub script whose target kiln deletes.

## Settled

- The API member gets no console script. `task api:dev` serves it; a served
  entry point is the application's decision (the story's **Design**).
- Rejected: seeding a `main()` that runs uvicorn; `uv init --lib` for the
  member.
- The stub removal in `_uv_init` stays, so the member's `__init__.py` stays
  empty.

## Current behaviour

- `src/rn_forge/kiln/modules/python/scaffold.py:409-441` `_uv_init` runs
  `uv init --package` for the member; uv writes a `main()` stub into
  `src/<module>/__init__.py` and
  `[project.scripts] <name>-api = "<module>:main"`. `:434-437` empties
  `__init__.py`.
- `:353-392` `_reconcile_pyproject` rewrites `project.scripts` only for
  `python-tool` and `python-app` roots (`:387-392`, via `DocumentUtils.update`
  then `_tidy`). Nothing touches the web member's.
- Observed 2026-11-16: scaffolding a `python-web-api` + `fastapi` config with
  `scaffold(root, KilnConfig.load(root))` leaves `apps/api/pyproject.toml`
  with `scripts == {'demo-api': 'demo_api:main'}` and an empty
  `src/demo_api/__init__.py`.

## Change

1. Test first (below), shown failing.
1. In `_reconcile_pyproject`, after the `_reconcile(...)` call: when
   `web and is_member`, read the document with
   `DocumentUtils.read_document(path)`, delete
   `document["project"]["scripts"]` if present, write it with
   `DocumentUtils.write_document(path, document)`, then call `_tidy(path)`.
   (`_tidy` at `:515-529` uses the same read and write.)
1. Nothing else in `scaffold.py` changes.

## Tests first

Append to `tests/modules/python/test_scaffold.py`, beside
`test_s4_9_1_7_scaffold_points_project_scripts_at_the_app` (`:446-459`), and
copy its shape and the `_web_api` helper's (`:474-478`) way of writing a config:

1. `test_s16_5_6_1_web_api_member_has_no_console_script`, parametrised over
   three cells: `python-web-api` + `backend = "fastapi"`, `python-web-api` +
   `backend = "django"`, `python-web-app` + `backend = "fastapi"` with
   `frontend = "angular"` (see `tests/modules/python/test_artifacts.py:161`
   for the web-app keys). For each: write the config,
   `scaffold(root, KilnConfig.load(root))`, read
   `root / config.packages[0] / "pyproject.toml"` with `tomllib`, assert
   `"scripts" not in document["project"]`, and assert the member's
   `src/*/__init__.py` reads `""`. Fails before the change on the first
   assertion: `scripts` is `{"demo-api": "demo_api:main"}`.
1. `test_s4_9_1_7_scaffold_points_project_scripts_at_the_app` is unchanged and
   still passes.
