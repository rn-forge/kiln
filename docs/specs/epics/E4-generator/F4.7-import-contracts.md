## S4.7.1 — kiln's contracts

**Status:** planned

`rn_forge.kiln` forbids `rn_forge.django`/`rn_forge.fastapi`/`rn_forge.web`;
`rn_forge.kiln.modules.*.checks` forbids `jinja2` and
`rn_forge.tooling.generation`, which keeps `kiln check` render-free
([ADR-0010](../../../adr/ADR-0010.md)); each concern module may import `core`
and not its siblings.

**Acceptance:**

- `.importlinter` holds the three contracts, and `lint-imports` reports each of
  them kept.
- `task lint` runs `lint-imports`.
- Each contract bites. A throwaway commit adds one forbidden import per
  contract, and the `lint-imports` output naming that contract as broken is
  recorded on this story.

## Acceptance

```bash
set -euo pipefail
cd rn-forge/kiln
out=$(mktemp)
uv run lint-imports >"$out"
grep -Eq 'Contracts: ([3-9]|[1-9][0-9]+) kept, 0 broken' "$out"                        # S4.7.1
task lint                                                                             # S4.7.1
```

Not scriptable: the recorded broken-contract output for each contract.
