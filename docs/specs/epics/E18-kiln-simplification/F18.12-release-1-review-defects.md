Three of [F18.10](F18.10-review-defects.md)'s defects, moved to release 1 by the
owner on 2026-11-13 so that adopters do not take them with the tag. They are
built after F18.9, with the rest of E18, and keep F18.10's properties:

1. The first test reproduces the defect and fails before the fix.
1. A test goes through the command or through doctor, never through a single
   check or helper alone.
1. Where a rendered file changes, `task kiln:apply` runs on this repository in
   the same change, and `task lint KILN_DOCTOR_FULL=1` passes.

Line numbers are at `6b3549b`.

## S18.12.1 — Doctor runs every check

**State:** New · **Depends on:** S18.8.1

*Was S18.10.1, moved 2026-11-13.*

`kiln-pin` is not in `checks.CHECKS`, so `kiln doctor` never runs it.

**Acceptance:**

- `kiln doctor` reports a `kiln-pin` finding on a repository with an unpinned
  `[kiln] ref`.
- A test asserts that every module under `modules/*/checks/` has an entry in
  `checks.CHECKS`.
- `tests/modules/core/checks/test_pin.py` drops its `xfail` (S18.5.2).

## S18.12.2 — A custom `web_dir` has one Nx project name

**State:** New · **Depends on:** S18.7.1

*Was S18.10.8, moved 2026-11-13.*

The Nx project name disagrees between modules (defect 8):

- `node/angular.py:117` creates the project as `web`, and `:168` removes it by
  that name.
- `node/scaffold.py:291-296` moves the app but never renames the project.
- `cicd/artifacts.py:37` hard-codes `web`.
- `tasks/artifacts.py:153` and `instructions/artifacts.py:157`, `:192` use
  `Path(web_dir).name`.

**Acceptance:**

- A `python-web-app` with `web_dir = "apps/portal"` renders the same project
  name in `project.json`, the tasks, the Sonar properties and `AGENTS.md`, and
  `task web:build` runs.

## S18.12.3 — `generate package` checks before it writes

**State:** New · **Depends on:** S18.6.3

*Was S18.10.10, moved 2026-11-13.*

`_add_package` writes `config.toml` and the package before `cycle.apply` can
refuse on drift, which leaves a package half added.

**Acceptance:**

- `kiln generate package` on a repository with drift exits 1 and leaves
  `git status` clean.
