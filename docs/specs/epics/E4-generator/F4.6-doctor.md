# F4.6 — doctor

Epic: [E4](index.md) · Phase step: D.6 · Design:
[doctor checks](design.md#doctor-checks) · **Depends on:**
[F4.3](F4.3-concern-modules.md) (the module checks), [S4.5.1](F4.5-cli.md) (the
declared app); S4.6.4 also on [S4.3.4](F4.3-concern-modules.md) (the `cicd`
module)

## S4.6.1 — One report across modules

**Status:** planned

Iterates modules in `archetype.toml` order and prints one `Finding` report:
checks 1–12, 8a, 8b.

**Acceptance:**

- For each check in the design table, a fixture triggers that check's code and
  no other error-severity code. There is one test per check.
- `kiln doctor` on a freshly created repo exits 0. With warnings only (8a, 11)
  it exits 0, and with any error-severity finding it exits 1.
- `--json` emits every finding with `code`, `severity`, `message` and `path`, in
  `archetype.toml` module order.
- `kiln apply`'s last step runs the same checks, and exits non-zero on an
  error-severity finding.

## S4.6.2 — The task-graph validator

**Status:** planned

`doctor/taskgraph.py` ported from taskkit `validator.py` with its tests.

**Acceptance:**

- taskkit's validator tests pass after the port, changed only in imports and
  finding codes.
- Each rule has a fixture that reports its `taskgraph.*` code. The rules are:
  exact public surface, wrappers-only root, internal inner tasks except
  `docs:*`, `desc` on every task, includes exist, `task:` refs resolve, no
  cycles, and no reserved-namespace collision.
- An unresolved `task <name>` in a workflow, `CLAUDE.md` or `AGENTS.md` reports
  `taskgraph.unresolved-ref` with its file and line (check 6).
- Removing a `required_validate` task from what `validate` reaches reports
  `gate.shrunk` (check 8).

## S4.6.3 — Many repos

**Status:** planned

`kiln doctor --all <path>…` runs the same checks over many repos and reports
them together.

**Acceptance:**

- Each path is checked independently. The text report is one table with a row
  per repo: path, error count, warning count.
- Every finding is attributed to its repo. In `--json`, `.repos[]` holds `path`
  and that repo's `findings`, and `.summary` holds `repos`, `errors` and
  `warnings` totals.
- A path that is not a kiln repo, or whose config fails to load, is an error for
  that repo only (`config.*`). The remaining repos are still checked.
- The exit status is 1 if any repo has an error-severity finding, and 0
  otherwise, whatever order the paths are given in.
- Tests cover three repos together: one clean, one with warnings only, one with
  errors.

## S4.6.4 — CI runs doctor where the workflow asks

**Status:** planned

`task lint` always runs `kiln check`, and also runs `kiln doctor` when the
`KILN_DOCTOR` task variable is non-empty. The generated `ci.yml` sets it on
pushes to the default branch and on `workflow_dispatch`, not on pull requests
([ADR-0010](../../../adr/ADR-0010.md)).

**Acceptance:**

- `task --dry lint` does not list `kiln doctor`; `task --dry lint KILN_DOCTOR=1`
  does.
- The rendered `ci.yml` sets `KILN_DOCTOR` only for a `push` to the default
  branch and for `workflow_dispatch`, and `actionlint` passes on it.

## Acceptance

```bash
set -euo pipefail
cd rn-forge/kiln
kiln_dir=$PWD
kiln() { uv run --project "$kiln_dir" kiln "$@"; }
task test                                                                             # S4.6.1, S4.6.2: one fixture per check and rule
s=$(mktemp -d)
for r in clean broken; do
  kiln new "$s/$r" --archetype python-app --docs none --yes </dev/null >/dev/null
done
printf '\n# edit\n' >> "$s/broken/Taskfile.yml"
mkdir "$s/not-kiln"
(cd "$s/clean" && kiln doctor)                                                        # S4.6.1: clean exits 0
rc=0
kiln doctor --all "$s/broken" "$s/clean" "$s/not-kiln" --json >"$s/all.json" || rc=$?
[ "$rc" -eq 1 ]                                                                       # S4.6.3: aggregate exit
jq -e '.summary.repos == 3 and .summary.errors >= 2' "$s/all.json"                   # S4.6.3: summary
jq -e --arg p "$s/clean" \
  '[.repos[] | select(.path == $p)] | length == 1 and all(.[0].findings[]; .severity != "error")' "$s/all.json"  # S4.6.3: attribution
jq -e --arg p "$s/broken" \
  '[.repos[] | select(.path == $p) | .findings[] | .code] | index("artifact.drift") != null' "$s/all.json"  # S4.6.3
jq -e --arg p "$s/not-kiln" \
  '[.repos[] | select(.path == $p) | .findings[] | .code | startswith("config.")] | any' "$s/all.json"  # S4.6.3: still reported
out=$(cd "$s/clean" && task --dry lint)
[[ $out != *'kiln doctor'* ]]                                                         # S4.6.4: not by default
(cd "$s/clean" && task --dry lint KILN_DOCTOR=1) | grep -q 'kiln doctor'              # S4.6.4
rg -q 'KILN_DOCTOR' "$s/clean/.github/workflows/ci.yml"                               # S4.6.4
```
