# S18.9.3 — The instructions and tasks renderers

Brief for
[S18.9.3](../F18.9-large-files-split.md#s1893-the-instructions-and-tasks-renderers),
at `56cc654`. The feature page's line numbers are stale: find each named
function by name. Paths are under `src/rn_forge/kiln/modules/`.

## Goal

Split the instructions context and the tasks renderer so that no function in
`modules/instructions/` or `modules/tasks/` is over 60 lines. No rendered file,
finding, message or exit code changes.

## Settled

- **`instructions/artifacts.py` `context()`** (100 lines, `:125`) splits into
  one small builder per bullet or paragraph it assembles (selectors, the API
  paragraph, tools, verbs, and so on), each returning its finished string.
  Each builder reads `KilnConfig`'s accessors (`is_web`, `is_web_app`,
  `is_node_lib`, `docs`, `ci`, `api_module`, …) instead of growing a string
  with order-dependent `+=`. `context()` assembles the dict from them. The two
  `api_text` literals (`:145`, `:152`) share their common first line as one
  constant or prefix.
- **`tasks/artifacts.py` `render`** (120 lines, `:61`) splits into
  `_validate_overrides(config, known)` (the unknown-override refusal, with its
  message), `_kiln_commands(config) -> tuple[str, str]` (the `kiln` and
  `kiln-devops` command lines, including kiln's own `uv run` case) and
  `_context(config, …) -> dict[str, object]` (the template context). `render`
  calls them, then renders.
- **The unused `root` arguments stay.** `Module.artifacts(self, config, root)`
  is the module contract (`base.py:65`), so `cicd/__init__.py` and
  `tasks/__init__.py` keep the parameter and their `del root`. Record that in
  `## Result`; the story asks for this to be noted.
- **References go**: `tasks/config.py:25` "(kiln ADR-0007)", the `S4.6.2` in
  `tasks/checks/layout.py:13`, and any ADR, story or decision reference, or
  design rationale, in the docstrings and comments of a file this story
  touches. A string that is rendered or is a finding message keeps its text.
