A configured check, on by default (`node-lib` also gets `pnpm audit`, a standard
check, in S15.2.4): `task` fails when a dependency's licence matches the deny
list (default `GPL-*`, `AGPL-*`, `UNKNOWN`) and the package is not in the ignore
list. It is a step of `task lint`, so `validate` runs it, with no job of its
own. Python uses `pip-licenses`; `node-lib` uses `pnpm licenses`, which
understands pnpm's layout. Both feed one matcher, `kiln-devops licenses`.

## S15.2.1 — `kiln-devops licenses` applies the policy

**State:** New

**Build — tests first,** in `tests/devops/test_licenses.py`, calling
`licenses.run(text, fmt, deny, ignore)` which returns the offender lines:

1. `test_s15_2_1_1_pip_licenses_json`: input
   `[{"Name":"a","Version":"1","License":"MIT"},{"Name":"b","Version":"2","License":"GPL-3.0-only"}]`,
   `fmt="pip-licenses"`, `deny=["GPL-*"]` returns `["b 2 GPL-3.0-only"]`.
1. `test_s15_2_1_2_pnpm_json`: input
   `{"MIT":[{"name":"a","versions":["1.0.0"]}],"Unknown":[{"name":"c","versions":["3.0.0"]}]}`,
   `fmt="pnpm"`, `deny=["UNKNOWN"]` returns `["c 3.0.0 Unknown"]`.
1. `test_s15_2_1_3_matching_is_case_insensitive_and_whole_string`: `LGPL-3.0` is
   not matched by `GPL-*`; `gpl-2.0-only` is.
1. `test_s15_2_1_4_multiple_licences`: a pip-licenses licence
   `MIT; GPL-3.0-only` is an offender, and each `;`-separated part is matched
   alone.
1. `test_s15_2_1_5_ignore`: a package named in `ignore` is never an offender.
1. `test_s15_2_1_6_cli`:
   `main(["licenses", "--format", "pip-licenses", "--deny", "GPL-*"])` with
   the offender input on stdin returns `1` and prints the offender line to
   stderr; with a clean input it returns `0`; with `not json` it returns `2`.

**Build:** new `src/rn_forge/kiln/devops/licenses.py` with `run`, and a
`licenses` subparser in `devops/cli.py` (`--format {pip-licenses,pnpm}`
required, `--deny` and `--ignore` repeatable, JSON on stdin). Match with
`fnmatch.fnmatchcase` on `casefold()`ed strings. An offender line is
`<name> <version> <licence>`; a pnpm package with several versions yields one
line each. `main` follows the other subcommands' error style
(`kiln-devops: <message>` on stderr).

**Acceptance:**

- The six tests pass, and `task validate` passes.

## S15.2.2 — Python repositories run it in `lint`

**State:** New · **Depends on:** S15.1.2, S15.2.1

**Build — tests first,** in `tests/modules/tasks/test_artifacts.py`:

1. `test_s15_2_2_1_python_lint_licenses_task`: a rendered `python-lib`
   `tasks/python.yml` has an internal task `lint:licenses` whose command is
   `uv run pip-licenses --format=json | {{.KILN_DEVOPS}} licenses --format pip-licenses --deny 'GPL-*' --deny 'AGPL-*' --deny 'UNKNOWN'`,
   preceded by `set -o pipefail;` as `lint:audit` is. The root
   `Taskfile.yml`'s `lint` calls `python:lint:licenses` right after
   `python:lint:audit`'s caller.
1. `test_s15_2_2_2_policy_reaches_the_task`: with
   `[ci.checks] licenses = { deny = ["GPL-*"], ignore = ["foo"] }` the command
   has one `--deny 'GPL-*'` and `--ignore 'foo'`.
1. `test_s15_2_2_3_off`: with `licenses = false`, neither the task nor the call
   renders.
1. In `tests/modules/python/test_scaffold.py`,
   `test_s15_2_2_4_pip_licenses_is_a_task_tool`: `"pip-licenses"` is in
   `TASK_TOOLS` and in `_DEV_GROUP`.

**Build:**

- `modules/python/scaffold.py`: add `"pip-licenses"` to `_DEV_GROUP` and
  `TASK_TOOLS`, in sorted position (after `"import-linter"`).
- `modules/tasks/artifacts.py`: context keys `licenses_enabled`,
  `licenses_deny`, `licenses_ignore` from `registry.enabled` and
  `ci.licenses_policy()`.
- `modules/tasks/templates/tasks/python.yml.j2`: the `lint:licenses` task after
  `lint:audit`; the root `Taskfile.yml.j2` `lint` list gains
  `- task: python:lint:licenses` under
  `{% if licenses_enabled and not node_lib %}`. Use the variable that holds
  the kiln-devops command that `tasks/ci.yml.j2` already uses
  (`grep KILN_DEVOPS`; if the template spells it differently, use that
  spelling in this command and the test).

**Acceptance:**

- The four tests pass, and `task validate` passes.
- `task self:golden:render`, then `task self:golden:compare BASE=HEAD`: every
  python cell gains `lint:licenses` and the dev group gains `pip-licenses`,
  and nothing else; every cell passes `task self:golden:validate`.

## S15.2.4 — `node-lib` runs `pnpm audit` in `lint`

**State:** New · **Depends on:** S15.1.1

The counterpart of `pip-audit` for `node-lib`, in the same stage: a standard
check, no switch, a step of `task lint`, so `validate` runs it.

**Build — tests first,** in `tests/modules/tasks/test_artifacts.py` and
`tests/modules/cicd/test_registry.py`:

1. `test_s15_2_4_1_node_lint_audit_task`: a rendered `node-lib` `tasks/node.yml`
   has an internal task `lint:audit` running
   `pnpm audit --prod --audit-level moderate`, described as needing the
   network, and the root `Taskfile.yml`'s `lint` calls `node:lint:audit`.
1. `test_s15_2_4_2_python_archetypes_have_none`: no Python archetype's rendered
   tasks or root `lint` mention `pnpm audit`.
1. `test_s15_2_4_3_registry_row`: `registry.CHECKS` has `pnpm-audit`,
   `standard`, archetypes `node-lib` only, verb `{stack}:lint:audit`, and
   `registry.configured_names()` is unchanged.

**Build:** `node.yml.j2`, the root `Taskfile.yml.j2` (`lint` list, beside
`python:lint:audit`'s caller) and one registry row. An accepted advisory is
recorded with pnpm's own `pnpm.auditConfig.ignoreGhsas` in the repository's
`package.json`; kiln renders no ignore list.

**Acceptance:**

- The three tests pass, and `task validate` passes.
- `task self:golden:validate` passes for the `node-lib` cell.
