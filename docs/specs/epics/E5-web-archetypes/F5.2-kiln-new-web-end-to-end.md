# F5.2 — `kiln new` end to end for the web archetypes

Epic: [E5](index.md) · **Depends on:**
[F5.1](F5.1-web-library-sets-and-modules.md); S5.2.1 on S5.2.2, whose fixtures
are the reconcile's test inputs

## S5.2.1 — Scaffold the frontend

**Status:** planned

`kiln new` end to end with `nx g` for the frontend; reconcile to `web_dir`.

**Acceptance:**

- `kiln new --archetype python-web-app --framework fastapi --frontend angular --yes`,
  with stdin closed, runs `nx g` and reconciles the frontend under `web_dir`.
- In the result, `uv sync`, `pnpm install` and `task validate` pass, and
  `kiln doctor` exits 0.
- kiln templates none of the scaffolder's output: no artifact path lies under
  `web_dir`.

## S5.2.2 — taskkit's fixtures become reconcile inputs

**Status:** planned

Move taskkit's
`tests/fixtures/repos/{python-pnpm-monorepo,python-django,python-fastapi*,python-angular-pnpm}`
into `tests/fixtures/repos/` as scaffold-reconcile inputs.

**Acceptance:**

- The four fixture sets exist under `tests/fixtures/repos/`.
- Each has a test that runs the reconcile over it and asserts the resulting
  layout.

## Acceptance

```bash
set -euo pipefail
cd rn-forge/kiln
kiln_dir=$PWD
for f in python-pnpm-monorepo python-django python-angular-pnpm; do
  test -d "tests/fixtures/repos/$f"                                                   # S5.2.2
done
compgen -G 'tests/fixtures/repos/python-fastapi*' >/dev/null                           # S5.2.2
task test                                                                             # S5.2.2: reconcile per fixture
s=$(mktemp -d)
uv run kiln new "$s/web" --archetype python-web-app --framework fastapi --frontend angular --docs mkdocs --yes --json </dev/null >"$s/new.json"  # S5.2.1
(cd "$s/web" && uv sync && pnpm install && task validate && uv run --project "$kiln_dir" kiln doctor)  # S5.2.1
```

Not scriptable: S5.2.1's check that no artifact path lies under `web_dir`, read
from `$s/new.json` against the recorded `web_dir`.
