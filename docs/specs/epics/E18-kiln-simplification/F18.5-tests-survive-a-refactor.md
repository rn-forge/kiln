Makes the test suite independent of how `src/` is laid out, so that
[F18.6](F18.6-commands-package.md) to [F18.9](F18.9-large-files-split.md) can
move code without editing tests, and so that
[F18.1](F18.1-tests-named-by-behaviour.md) renames tests in files that are
already organised by subject. Every story changes tests only, never `src/`.

Every story keeps these properties:

1. No test is deleted or weakened. A test that moves keeps its body. The number
   of collected tests is unchanged, unless the story says it merges tests by
   parametrizing them, and then the parameter count makes up the difference.
1. `task validate` passes before and after.

Line numbers are at `6b3549b`.

## S18.5.1 — Tests reach `commands` only through its public names

**State:** New · **Depends on:** —

The tests patch and call names that are private to `commands.py`, or that it
only imports. Once `commands` is a package, a
`monkeypatch.setattr(commands, ...)` on a name bound in a submodule stops taking
effect, and nothing fails.

**Build.**

- `tests/conftest.py:183-206` (at `6da1438`): the autouse `_default_owner` wraps
  `commands.new` for all 1,561 tests. Replace it with a `new_repo(...)` helper
  (or fixture) that passes `owner="rn-forge"`, and call that helper wherever a
  test now calls `commands.new` without an owner. Tests that check the owner
  rule call `commands.new` directly.
- Patch each scaffold step where it is defined, not on `commands`:
  `instructions_scaffold` (`tests/test_new.py:479`, `:548`),
  `python_add_package` (`:875`), and `scaffold_backend`, `reconcile_backend`,
  `scaffold_node`, `reconcile_node` and `format_node` (`:1151-1159`). If `new`
  binds them by `from … import`, a patch at the definition does not reach it.
  In that case the story records it, and S18.6.2 changes those imports to
  module imports.
- Import `ConfigManager` from `rn_forge.kiln.modules.core.config.manager`, not
  through `commands` (`tests/test_new.py:190`, `:215`;
  `tests/modules/cicd/test_artifacts.py:2735`).
- Private names: `_FLAG_NAMES` (`tests/test_new.py:58`), `_flag_layer` (`:114`,
  `:121`, `:182`, `:206`, `:223`;
  `tests/modules/cicd/test_artifacts.py:2727`), `_CONFIG_HEADER` (`:788`),
  `_write_config` (`tests/modules/core/test_catalog.py:27`) and
  `_fail_on_errors` (`tests/test_doctor.py:484-488`). Test the same behaviour
  through `commands.new` or `commands.apply`. A test that cannot be rewritten
  without the private name is listed in the story, and it moves with the name
  in S18.6.2.
- `tests/test_new.py:586` reads `inspect.getsource(commands._stage)`. Replace it
  with a behavioural check of the same rule (`RNF_HOME` is not set in the
  staged run).

**Acceptance:**

- No test names `commands.<_private>`, and no test calls
  `monkeypatch.setattr(commands, …)`. A test greps `tests/` for both and fails
  on a match.
- The properties hold.

## S18.5.4 — Test files follow the source, by subject

**State:** New · **Depends on:** S18.5.2

`tests/modules/cicd/test_artifacts.py` (3,814 lines) and
`tests/modules/tasks/test_artifacts.py` (3,648 lines) hold 27% of the test
lines, and are organised by story banner. `tests/test_new.py` is 1,207 lines.
Splitting them before F18.1 keeps each rename story small.

**Build.**

- Split the two `test_artifacts.py` files at their `# S<id> —` banners into
  topic files, such as `test_workflow_security.py`, `test_node_ci.py`,
  `test_sonar.py`, `test_release.py` and `test_pages.py`. The banners go.
- Split `tests/test_new.py` by subject into `tests/commands/test_new_*.py`:
  flags, staging, owner, packages and node. Move the other command tests
  (`test_apply`, `test_diff`, `test_prompt`, `test_config_lifecycle`,
  `test_lifecycle`, `test_cli_surface`, `test_generate_package`) into
  `tests/commands/`.
- Move `tests/test_golden_matrix.py` to `tests/scripts/`, and move
  `tests/test_conftest.py` and `tests/test_checks_are_render_free.py` to
  `tests/suite/`.
- Read-only tests in the new `test_new_*.py` files use the session fixture
  `rendered` in place of their own full `commands.new` render, where they need
  no other flag.

**Acceptance:**

- No test file under `tests/` is over 1,200 lines.
- No `# S<digits>` banner remains under `tests/`.
- The properties hold. The collected count is unchanged, because a test that
  moves to `rendered` keeps its name.
