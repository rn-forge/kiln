# S19.4.1 — The starter's imports are stable at any name length

Brief for
[S19.4.1](../F19.4-fastapi-starter-imports.md#s1941-the-starters-imports-are-stable-at-any-name-length),
at `feature/v1` after `6920f7d`.

## Goal

The FastAPI starter writes every first-party import in parenthesised form with a
trailing comma, so ruff's import sorter and formatter accept the seeded files
whatever the package name's length.

## Settled

- Every `from {{ module }}... import ...` line in the four FastAPI starter
  templates becomes the parenthesised form, one name per line, with a trailing
  comma. ruff's magic trailing comma keeps that form at any length:

    ```python
    from {{ module }}.domain.errors import (
        ItemNotFound,
    )
    ```

- Third-party and standard-library imports do not change.

- The check is `ruff check --isolated --extend-select I` and
  `ruff format --isolated --check`. The test runs them from the API member
  root, with the package's `__init__.py` present, so ruff sees the package as
  first-party.

- Test names describe behaviour, with no spec IDs.

- Rejected (do not build): shortening module names, setting a larger
  `line-length` in the generated `pyproject.toml`, ignoring `I001`, and
  parenthesising only when the name is long (a conditional in the template).

## Current behaviour

- `src/rn_forge/kiln/modules/python/templates/starter/fastapi/app.py.j2` has
  `from {{ module }}.domain.errors import ItemNotFound` and
  `from {{ module }}.http.items import router`. `items.py.j2` has the first of
  these. `test_app.py.j2` has `from {{ module }}.app import app`.
- For the name `python-web-app-backend-fastapi-frontend-angular`, the module is
  `python_web_app_backend_fastapi_frontend_angular_api`, and the
  `domain.errors` line is 90 characters long. ruff reports `I001` in `app.py`
  and `http/items.py`. It wants the line parenthesised.
- The existing `test_web_api_starter_is_formatter_stable` passes today. It runs
  only `ruff format`, and its longest name (`LONG_NAME`, 40 characters) gives
  an 83-character line.
- So test 1 below passes for `demo` and fails for the long name: `ruff check`
  exits 1 with `I001` in `app.py` and `http/items.py`.
- The `test_fastapi_starter_artifacts` assertions on
  `"from demo_api.... import ..."` pass today. They fail after the change
  unless updated as in test 2.
