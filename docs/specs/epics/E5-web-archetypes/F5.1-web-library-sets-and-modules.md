# F5.1 — Library sets, and the modules gain the web shapes

Epic: [E5](index.md) · **Depends on:** [E4](../E4-generator/index.md);
`rn-forge-fastapi` at its plan's acceptance in pykit

## S5.1.1 — Web library sets

**Status:** planned

`python-web-api`/`python-web-app` take commons → web → `rn-forge-django` or
`rn-forge-fastapi` (+ `rn-forge-cli` for management commands), `[codegen]`
extras in dev only (D37).

**Acceptance:**

- For each web archetype and framework, the required set is commons, cli, web
  and the framework package.
- The framework's `[codegen]` extra appears only in the dev group.
- The dependency check refuses a render that lacks `rn-forge-web`, and one with
  `[codegen]` in runtime dependencies (one test each).

## S5.1.2 — Modules gain the web shapes

**Status:** planned

`python` module gains the web shapes; `tasks` gains `tasks/api.yml` and, for
`python-web-app`, `tasks/web.yml` (`pnpm nx run-many -t lint|test|build`);
`cicd` gains pnpm/node setup; `forbidden_tools` adds `pnpm npx nx`.

**Acceptance:**

- `python-web-app` renders `tasks/api.yml` and `tasks/web.yml`. `python-web-api`
  renders `tasks/api.yml` and no `tasks/web.yml`.
- Only `python-web-app`'s CI sets up pnpm and node, and `actionlint` passes on
  both.
- A workflow that calls `pnpm`, `npx` or `nx` directly fails
  `kiln doctor --only ci-entrypoint`.

## S5.1.3 — `framework` stays a flag

**Status:** planned

`framework = fastapi|django` changes only `tasks/api.yml` primitives and the
scaffold reconcile — never topology or task graph
([ADR-0005](../../../adr/ADR-0005.md)).

**Acceptance:** for `python-web-app` with `angular`, `django` and `fastapi`
render the same artifact paths and the same task names. Their managed artifacts
differ only in `tasks/api.yml`.

## Acceptance

```bash
set -euo pipefail
cd rn-forge/kiln
kiln_dir=$PWD
kiln() { uv run --project "$kiln_dir" kiln "$@"; }
task test                                                                             # S5.1.1, S5.1.2
s=$(mktemp -d)
for fw in django fastapi; do
  kiln new "$s/$fw" --archetype python-web-app --framework "$fw" --frontend angular --docs none --yes --json </dev/null \
    | jq -r '.artifacts[].path' | sort >"$s/$fw.paths"
  (cd "$s/$fw" && task --list-all --json) | jq -r '.tasks[].name' | sort >"$s/$fw.tasks"
done
test -s "$s/fastapi.paths"
diff "$s/django.paths" "$s/fastapi.paths"                                             # S5.1.3: same artifacts
diff "$s/django.tasks" "$s/fastapi.tasks"                                             # S5.1.3: same task graph
```
