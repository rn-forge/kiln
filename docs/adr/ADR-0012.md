# ADR-0012 — Every repository publishes one MkDocs site, whatever its language

**Status:** accepted (2026-10-01) · **Scope:** the docs site of every repository
kiln generates

## Decision

A repository's docs site is built by MkDocs, pinned and run through `uv`,
whatever language the repository is written in. Each language keeps its own API
and component reference tools: mkdocstrings for Python, Compodoc and Storybook
for Angular, Javadoc for Java. Their static output is assembled under the built
site, at `api/` or `storybook/`, and each assembled site's entry point is
checked.

mdformat formats every Markdown file. A repository that uses Prettier lists
`*.md` in `.prettierignore`.

## Consequences

- One nav and link policy, one docs checker, and one build and publish pattern
  across rn-forge repositories.
- A Node repository needs `uv` for its docs. `uv` is already in every
  repository's toolchain.
- MkDocs checks Markdown links, but not links inside the assembled HTML. Each
  assembled site gets its own entry-point check.
- Prettier and mdformat never format the same file. Derived regions only need to
  be mdformat-stable.
- Assembling Node and Java sites is not built yet. It belongs to the Node
  archetypes ([E9](../specs/epics/E9-node-archetypes/index.md)), and a Java
  archetype is an idea.

## Influences

[E13's design](../specs/epics/E13-docs-work-model/design.md#one-site-per-repository);
the formatting rule in [the reference](../reference/standard-repo.md).

## Alternatives considered

- **VitePress for Node repositories.** It is a capable generator. But two
  generators mean two nav and link policies, and kiln would need a second docs
  checker.
- **Maven Site for Java repositories.** Its Markdown lives under
  `src/site/markdown/`, outside the shared `docs/` layout, and multi-module
  sites need extra staging.
- **Publish each generated site separately.** This is how ngkit worked on
  2026-09-30. There was no single entry point, and nothing checked links
  between the sites.
- **Let Prettier format Markdown too.** In a Node repository, Prettier rewrote
  kiln's seeded tables, emphasis and list indents. The two formatters would
  fight over every derived region.
