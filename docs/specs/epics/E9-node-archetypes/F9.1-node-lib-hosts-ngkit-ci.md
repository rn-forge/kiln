Added 2026-10-13, while E9 is deferred, so that the gap is written down before
the epic unparks. ngkit's CI is written as a portable template. Its
`docs/architecture/ci-template.md` lists template-owned files that name no
project, and repository-owned declarations (`nx.json`, project targets and tags,
`.nvmrc`, `packageManager`). That split maps onto kiln's split between generated
and seeded files. The commands are what do not fit: ngkit has no `Taskfile.yml`
(`package.json` `scripts` is `{}`), and its workflows call `pnpm exec nx`,
`pnpm dlx nx`, `npm pack` and `node tools/ci/*.mjs` directly. `ci-entrypoint`
fails each of those calls once `pnpm npx nx ng` are in a node archetype's
`forbidden_tools`
([F5.1](../E5-web-archetypes/F5.1-web-library-sets-and-modules.md)).

The shared patterns are F6.3's for every archetype: timeouts, `ci-ok`, the
published release as the record, and pins. What follows is node-only. The
evidence is ngkit's `.github/` and `tools/ci/`, read on 2026-10-13.

## Decisions

Answered by the owner on 2026-10-14, and recorded in
[ADR-0015](../../../adr/ADR-0015.md).

1. **Release tag:** `v<version>` for one fixed group, as ngkit's ADR-0003 has
   it. There is no per-package option.
1. **Nx Cloud:** `nx start-ci-run` and `nx fix-ci` get a named exemption from
   `ci-entrypoint` for `node-lib`, and nothing else does.
1. **Release trigger:** `[ci] release = "nx-dispatch"`, the default for
   `node-lib`. The release commit is pushed with a GitHub App token
   (`actions/create-github-app-token`), as ngkit's `release.yml` does since
   `1934be3` (2026-10-14).
1. **`tools/ci/` helpers:** generated files. The generated-path list gains
   `tools/ci/*.mjs` for `node-lib`.
1. **Task verbs:** as proposed. The root verbs map onto Nx, and the CI-only
   steps are internal `ci:*` tasks.

## Stories

Outlines only. Each is written as a build-list once the `node-lib` archetype
exists.

- **S9.1.1 — A node setup action.** It installs pnpm, Node from `.nvmrc`, and
  go-task, then runs `pnpm install --frozen-lockfile`, with no uv. It has
  `registry-url` and the optional Nx Cloud start. Pins are added for
  `nrwl/nx-set-shas`, `actions/cache`, `actions/upload-artifact` and
  `actions/download-artifact`.
- **S9.1.2 — Affected CI.** `ci-cloud`/`ci-local`, chosen by `USE_NX_CLOUD`.
  Every step is `task`. Playwright is cached, and the `release/**` triggers
  are added.
- **S9.1.3 — Node Sonar.** A JS/TS `sonar-project.properties` template with lcov
  discovery, and the `dependabot[bot]` skip.
- **S9.1.4 — `package`.** `pack`, `verify-dist` and `verify-consumer` through
  `task`, with the tarballs uploaded.
- **S9.1.5 — Dispatch release.** `release.yml` with the green-CI gate,
  `nx release`, resume, the rolling `latest`, `published-install`, and npm
  OIDC behind a flag.
- **S9.1.6 — ngkit-shaped repository.** A scratch `node-lib` repository with two
  publishable libraries, an app and a Storybook passes `task validate`, and
  its rendered workflows pass `actionlint`. This is the node counterpart of
  [S6.1.1](../E6-rebuild-the-repos/F6.1-pykit-skeleton.md#s611-a-pykit-shaped-repository-passes-its-own-gate).
