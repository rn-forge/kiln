# S18.11.2 — `ci-pins` skips managed files

Brief for
[S18.11.2](../F18.11-checks-police-repository-content.md#s18112-ci-pins-skips-managed-files),
at `feature/v1` after `86e36ef`.

## Goal

`ci-pins` reads only the workflows and actions the repository owns. Its two
rules over what kiln renders become a render test over every archetype, so no
rule is lost.

## Settled

- In `src/rn_forge/kiln/modules/cicd/checks/pins.py`, add the public
  `scan(label, text) -> list[Finding]`, returning `_check_uses` then
  `_check_permissions` for one file, and export it. `check` calls it.
- `check` skips a path that `state.json` records with `"kind": "managed"`. It
  reads the entries as `_check_owned_text` in `tasks/checks/layout.py` does
  (`DocumentUtils.read(root / umbrella.STATE_PATH)`, `entries`, each entry's
  `path`). With no `state.json`, nothing is skipped. A seeded file, or one
  kiln never wrote, is scanned.
- Update the module docstring to say the check reads repository-owned files.
- Rejected (do not build): skipping by path prefix, and a config switch.

## Current behaviour

- `check` scans every `*.yml` and `*.yaml` under `.github/workflows/` and
  `.github/actions/`, kiln's own rendered files included.
- Test 1 below fails: on a rendered, applied `python-app` with the first `uses:`
  SHA in `.github/workflows/ci.yml` replaced by `v4`, `run_check` returns
  `["ci.unpinned"]` instead of `[]`.
- Test 3 fails with `AttributeError` (no `pins.scan`) until it exists.
- `tests/modules/cicd/checks/test_pins.py`'s eight tests write files into a
  `repo` with no `state.json`, so they pass unchanged.

## Change

- **Change:** `pins.py` as above.
- **Leave alone:** `cicd/config.py`, `tests/modules/cicd/test_hooks.py` and
  `test_every_cell_passes_ci_pins_and_ci_hooks` in it (another story edits
  both; that test still passes and the new render test covers its pin half),
  and every template.

`from tests.modules.cicd.support import _root` and
`from rn_forge.kiln.modules.core import cycle`:

   `root = _root(tmp_path, "python-app")`,
   `cycle.apply(root, home=tmp_path / "home")`; edit
   `.github/workflows/ci.yml`, replacing the first `@<40 hex>` with `@v4`
   (`re.sub(..., count=1)`); assert `_codes(root) == []`.
1. `test_a_repository_workflow_beside_managed_ones_is_scanned`: the same applied
   root, plus `.github/workflows/extra.yml` holding an unpinned `uses:` with
   `permissions: {}`; assert `_codes(root) == ["ci.unpinned"]`. It passes
   before and after.

In `tests/modules/cicd/test_workflow_security.py` (it has `_rendered` and the
cell helpers; import `_cell_root`, `SECURITY_CELLS` from
`tests.modules.cicd.support` and

1. `test_every_rendered_workflow_and_action_is_pinned`, parametrized over
