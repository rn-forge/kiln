# F3.2 — Pins, per ADR-0005

Epic: [E3](index.md) · Decision: [ADR-0005](../../../adr/0005-archetypes.md) ·
**Depends on:** nothing

## S3.2.1 — Every golden pins the branch

**Status:** planned

Every rn-forge requirement in every golden — including
`python-lib/packages/golden-{alpha,beta}`, which still pin
`rn-forge-commons-v0.2.2` — names `@feature/upgrade`.

**Acceptance:**

- No golden `pyproject.toml` pins a pykit tag.
- Every pykit git requirement in every golden names `@feature/upgrade`, and
  there is at least one.

## S3.2.2 — Locks reach current pykit

**Status:** planned

`uv lock --upgrade` in each golden, so the lock reaches `f59c40f` or later. Path
sources are not used for pykit packages in goldens: they must stay CI-capable.

**Acceptance:**

- Every pykit commit recorded in a golden `uv.lock` descends from `f59c40f`.
- No golden declares a path source for a pykit package.
- `task validate` passes in `golden/python-lib`. `python-app` and `python-tool`
  break on this lock until F3.1 ports them, and F3.1's acceptance proves them.

## Acceptance

```bash
set -euo pipefail
absent() { local rc=0; rg -q --hidden --glob '!.git' "$@" || rc=$?; [ "$rc" -eq 1 ]; }
cd rn-forge/kiln/tests/fixtures/golden
pkg='rn-forge-(commons|cli|tooling|web|django|fastapi)'
absent -g pyproject.toml "$pkg"'-v[0-9]' .                                           # S3.2.1: no tag pins
count() { rg -c --no-filename -g pyproject.toml "$1" . | awk '{s+=$1} END {print s+0}'; }
reqs=$(count "$pkg"' @ git\+')
pinned=$(count "$pkg"' @ git\+[^"]*@feature/upgrade#')
[ "$reqs" -gt 0 ] && [ "$reqs" -eq "$pinned" ]                                        # S3.2.1
absent -g pyproject.toml "$pkg"'\s*=\s*\{[^}]*path\s*=' .                             # S3.2.2: no path sources
shas=$(rg -o --no-filename -g uv.lock 'pykit[^"#]*#([0-9a-f]{40})' -r '$1' . | sort -u)
for sha in $shas; do git -C ../../../../pykit merge-base --is-ancestor f59c40f "$sha"; done  # S3.2.2
(cd python-lib && uv sync && task validate)                                           # S3.2.2
```
