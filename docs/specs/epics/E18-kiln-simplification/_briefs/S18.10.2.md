# S18.10.2 — `doctor --full` reports every blocking action

Brief for
[S18.10.2](../F18.10-review-defects.md#s18102-doctor-full-reports-every-blocking-action),
at `feature/v1` after `523016f`.

## Goal

`kiln doctor --full` turns each blocking plan action (`CONFLICT`, `DRIFT`,
`MISSING`) into an error finding that names the path, so a repository that
`kiln apply` would refuse never passes `--full`.

## Settled

- `_CODES` in `src/rn_forge/kiln/commands/doctor.py` gains
  `Action.CONFLICT: "artifact.conflict"`, `Action.DRIFT: "artifact.drift"` and
  `Action.MISSING: "artifact.missing"`. The last two are the codes the
  render-free `generated` check already uses.
- `full` builds the message by action. The stale actions keep today's text. A
  blocking action (`generation.BLOCKING_ACTIONS` is
  `{DRIFT, CONFLICT, MISSING}`) says
  `f"is {change.action.value} against a fresh render; resolve it, then run kiln apply"`.
  Severity stays `ERROR`; seeded changes stay skipped.
- `_findings` drops a `full` finding whose `(code, path)` is already among
  `checks.run`'s findings, so a drifted file is reported once, not twice.
- Rejected (do not build): new codes for drift and missing, and moving the
  blocking check into `checks.run`.

## Current behaviour

- `_CODES` has no entry for the three actions, so `full()` skips them
  (`_CODES.get` returns `None`).
- Probed on a rendered `python-app` copy: with `.editorconfig`'s entry removed
  from `.rn-forge/kiln/state.json`, `cycle.plan(...)` holds
  `(.editorconfig, conflict)`, and `doctor_full(copy)` and `checks.run(copy)`
  both return `[]`. `commands.doctor([copy], full=True)` returns without
  raising.
- With `Taskfile.yml` edited and `tasks/quality.yml` deleted, the plan holds
  `drift` and `missing`, `full()` returns `[]`, and `checks.run` already
  reports `artifact.drift` and `artifact.missing` for them. So only the
  conflict case fails today; the other two guard the de-duplication.

## Change

- **Change:** `_CODES` and `full` in `commands/doctor.py` as above, and the
  de-duplication in `_findings`.
- **Leave alone:** `cycle.py`, `checks/generated.py`, `apply.py` and every spec
  page except this brief's `## Result`.
