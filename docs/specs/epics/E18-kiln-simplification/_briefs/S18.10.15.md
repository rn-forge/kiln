# S18.10.15 — Docs links are checked once, against the real `.gitignore`

Brief for
[S18.10.15](../F18.10-review-defects.md#s181015-docs-links-are-checked-once-against-the-real-gitignore),
at `feature/v1` after `523016f`.

## Goal

A broken docs link or anchor is reported once, by `docs-site`, and a link to a
page under any `.gitignore` pattern (a glob such as `docs/api/**` included)
counts as generated.

## Settled

- `docs-site` owns links. Delete `_check_links` and its call from
  `src/rn_forge/kiln/modules/docs/structure.py`. `docs-structure` keeps
  `_check_no_underscore_refs` and every other check. Remove what becomes
  unused there: `package_mounts`, `resolve_link`, `MarkdownUtils`, `Mapping`
  and the `packages` parameter of `check_structure` (update its one caller,
  `modules/docs/checks/structure.py`).
- Glob matching uses `pathspec`, already a direct dependency (`pathspec>=1.1` in
  `pyproject.toml`, locked) and already used by `excluded_docs` in
  `modules/docs/mkdocs.py`. `Site.__init__` builds
  `self.ignored = GitIgnoreSpec.from_lines(<the lines of root/.gitignore>)`,
  an empty spec when the file is absent. This replaces `_generated_prefixes`
  and `self.generated`.
- `Site.is_generated(path)` is true when `path` is under `self.root` and
  `self.ignored.match_file(path.relative_to(self.root).as_posix())`. A path
  outside the root is not generated. Negations (`!docs/api/index.md`) and
  directory-only, anchored and `**` patterns follow gitignore rules.
- Rejected (do not build): an `fnmatch` subset, a new dependency, and calling
  `git check-ignore`.

## Current behaviour

- Probed on a `python-app` repo with `docs/_areas.yml`, `mkdocs.yml` and
  `docs/index.md` holding `[x](api/index.md)` (no such file): `docs/api/` in
  `.gitignore` gives one `docs.broken-link` from `docs-structure` and none
  from `docs-site`. `docs/api/**` and `api/` give one from each. With no
  ignore line and `missing.md`, both report it, so `kiln doctor` prints two.
- `_generated_prefixes` reads each line as a literal path, so `docs/api/**`
  resolves to a path that is not a directory, and `api/` resolves outside
  `docs/`.

## Change

- **Change:** `modules/docs/site.py` (`Site.__init__`, `is_generated`, drop
  `_generated_prefixes`), `modules/docs/structure.py` and
  `modules/docs/checks/structure.py`, as settled.
- **Leave alone:** `parsed.py`, `mkdocs.py`, `tests/test_doctor.py` and every
  spec page except this brief's `## Result`.
