# ADR-0001 — One owner per managed file, or per fenced block

**Status:** accepted

## Context

Across four repos, `Taskfile.yml` had three owners: a kit that generated it, a
kit that adopted it, and a human who edited it. Apollo's working tree was broken
at the time of the review because an `adopt` run replaced the file and silently
dropped five lint gates, and CI still called a task that no longer existed (F1).
Byte-identical scripts had been copied into four repos and had drifted into four
forks (F2, F3); each kit wrote its own `.gitignore` block with no agreement about
who owned the file (F14).

agentkit ADR-0021 already said "install only what CI runs", which is the same
instinct one step short: it says what gets written, not who owns it afterwards.

## Decision

**kiln owns anything deterministic. Every managed file — or every fenced block
inside a shared file — has exactly one owner.**

1. All repo-specific logic that CI runs is committed. Standard logic is
   generated by kiln; repo-specific logic stays repository-owned and is wired in
   through config, never by editing a generated file.
2. If a script differs per repo only by a list or a path, that list is config in
   the script's own header, not a fork.
3. Two owners never write the same bytes. Shared files (`.gitignore`,
   `CLAUDE.md`, `AGENTS.md`, `mkdocs.yml`) are partitioned into fenced blocks;
   each block has one owner; the file body belongs to whoever seeded it.
4. kiln may invoke agentkit as a subprocess. agentkit never knows kiln exists.
5. Judgement is not automated. Where a human or agent must decide, kiln's docs
   hold a runbook, not a skill ([ADR-0007](0007-runbooks-not-skills.md)).

Ownership is per *file or block*, not per tool, which is what makes rule 3
mechanical rather than a convention.

## Consequences

- A file can be checked against its owner's render, which is what makes drift
  detectable at all ([ADR-0004](0004-ci-runs-committed-code.md)).
- The cost is a fence in four shared files, and a config key for every list that
  used to be a fork.
- "Who owns this?" stops being a judgement call, so it stops being answered
  differently in each repo. The answer is a table
  ([ADR-0002](0002-the-ownership-table.md)).
