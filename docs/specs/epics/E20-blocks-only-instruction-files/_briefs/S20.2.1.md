# S20.2.1 — The block's opening paragraph links `README.md`

Brief for
[S20.2.1](../F20.2-block-links-readme.md#s2021-the-blocks-opening-paragraph-links-readmemd),
at `feature/v1` after the F20.2 spec commit.

## Goal

kiln's `AGENTS.md` block links `README.md` in its opening paragraph, in every
archetype and docs profile.

## Settled

- In `src/rn_forge/kiln/modules/instructions/templates/block.md.j2`, the opening
  paragraph under `## Repository standard (kiln)` becomes exactly (the line
  breaks are mdformat's at wrap 80):

    ```markdown
    This repo is generated and checked by [kiln](https://github.com/rn-forge/kiln).
    What it is and how to set it up are in [README.md](README.md). The standard,
    rendered for this repo's archetype and docs profile, is
    [.rn-forge/kiln/standard.md](.rn-forge/kiln/standard.md). Read it before
    changing anything structural.
    ```

- Nothing else in the block changes. No new section, no new context key.

- kiln's own `AGENTS.md` body is the owner's and is not edited; only its block
  changes, through `task kiln:apply`.

- Test names describe behaviour, with no spec IDs.

## Current behaviour

- The paragraph reads "This repo is generated and checked by [kiln](%E2%80%A6).
  The standard, rendered for …". No line in the block links `README.md`, so
  the new test fails for every profile on the `[README.md]` assertion.
- `test_the_block_text_is_unchanged` in
  `tests/modules/instructions/test_artifacts.py` asserts the heading and the
  standard link; it passes before and after.

## Change

- **Change:** the paragraph in `block.md.j2`, as settled.
- **Then:** `task kiln:apply` updates the `rn-forge kiln` block in kiln's own
  `AGENTS.md` and `.rn-forge/kiln/state.json`. Those are the only generated
  changes allowed.
- **Leave alone:** every other template, every Python source file, the body of
  kiln's `AGENTS.md`, and every spec page except this brief's `## Result`.

## Tests first

In `tests/modules/instructions/test_artifacts.py`, add
`test_the_block_links_the_readme_in_every_docs_profile`, parametrized over
`profile` in `["mkdocs", "external", "none"]`. Build the root with the file's
existing `_root(tmp_path, profile=..., docs_extra=...)` helper (for `external`,
pass `docs_extra='external_url = "https://docs.example.com/demo"\n'`, as
`test_external_renders_the_url_into_the_block` does), render with `_rendered`,
and assert, on the block (`[BLOCK_KEY]`):

- `"What it is and how to set it up are in [README.md](README.md)." in " ".join(block.split())`

Run it before the change and confirm it fails for all three profiles.
