# S7.11.1 — The standard and the release page state the rule

Brief for
[S7.11.1](../F7.11-dependabot-and-the-release-cut.md#s7111-the-standard-and-the-release-page-state-the-rule),
at `feature/v1` after `116aa35`.

## Goal

The rendered `standard.md` and `docs/releases/_structure.md` tell a repository
that Dependabot pull requests are absorbed by the release cut, not merged into a
branch that publishes. Text only; `dependabot.yml` does not change.

## Settled

- Owner, 2026-11-21 (F7.11 Context): Dependabot stays automatic against `main`;
  the release cut absorbs open Dependabot updates on the release branch before
  the cut; kiln states only the generic rule, the repository's release runbook
  says how.
- No `target-branch` in `dependabot.yml` (F7.11 Considered and rejected).

## Current behaviour

- `src/rn_forge/kiln/modules/instructions/templates/standard.md.j2:357-359`, in
  `## CI checks`, unconditional: "A repository-owned workflow is allowed only
  for a scheduled or non-gating run; it keeps its own action pins current
  through Dependabot, which ignores the actions kiln pins." There is no rule
  on what to do with Dependabot pull requests.
- `src/rn_forge/kiln/modules/docs/templates/docs/releases/_structure.md.j2:20`:
  the `**Exit criteria**` bullet reads only "what must hold for the release to
  ship." It is listed in `src/rn_forge/kiln/modules/docs/artifacts.py:38`;
  find which docs profiles render it there and test each one.
- A test asserting the new sentences fails today because the text is absent.

## Change

- **Change:**
    - `standard.md.j2`: right after the paragraph at lines 357-359 (outside any
      `{% if %}`, so every archetype gets it), add a paragraph with exactly this
      text:

        ```markdown
        **Dependabot and releases.** Dependabot pull requests are not merged into a
        branch that publishes. A release absorbs the open Dependabot updates on its
        release branch before the cut, and the repository's release runbook says
        how. Security updates are the exception: they ignore `target-branch` and
        open against the default branch, so they ship as an urgent patch release,
        not held for the next cut.
        ```

    - `releases/_structure.md.j2`: extend the Exit criteria bullet, keeping the
      nested-list indentation of its siblings, to:

        ```markdown
            - **Exit criteria**: what must hold for the release to ship. One criterion
              stands on every release: no Dependabot pull request is open against the
              default branch, or each open one is listed on the release page as
              deferred, with its reason.
        ```

    - Tests (below), then `task kiln:apply` in the worktree root so kiln's own
      `.rn-forge/kiln/standard.md` and `docs/releases/_structure.md` match.
- **Leave alone:** `modules/cicd/templates/dependabot.yml.j2`,
  `modules/cicd/artifacts.py`, every other template, and every spec page
