# F3.1 — Port `golden/python-app` and `golden/python-tool` to the Part E API

Epic: [E3](index.md) · **Depends on:** [F3.2](F3.2-branch-pins.md). The goldens'
locks predate Part E, so the port cannot pass `task validate` until S3.2.2 has
moved them.

## S3.1.1 — The entry module is declared, not written

**Status:** done

`main.py` becomes `app = CliApp.from_config(CONFIG)` with no `main()` and no
`run`; `[project.scripts]` points at `golden_app.main:app`; `commands.py`
imports `console` from `rn_forge.commons`.

**Acceptance:**

- Neither golden's `src/` defines `main`.
- `[project.scripts]` names `golden_app.main:app` and `golden_tool.main:app`.
- `golden-app --help` and `golden-tool --help` exit 0 and list every command in
  their `commands.py`.
- `task validate` passes in both goldens, against a lock at or after pykit
  `f59c40f`.

## S3.1.2 — No prose names the deleted API

**Status:** done

Fix every prose reference to `rn_forge.cli.declare` / `build_app` in both
goldens' `README.md`, `docs/architecture/repository-shape.md`,
`docs/adr/ADR-0001.md` and the `config.toml` comment.

**Acceptance:** nothing in either golden, hidden files included, matches
`rn_forge.cli.declare`, `build_app` or `from rn_forge.cli import console`.

## S3.1.3 — No deleted `[cli]` keys

**Status:** done

Remove any key Part E deleted (`log_options`, `output_options`) from either
`[cli]` table.

**Acceptance:** neither golden contains `log_options` or `output_options`, and
both CLIs start (S3.1.1's `--help` check).

## Acceptance

```bash
set -euo pipefail
# absent ARGS… — passes only if rg ran cleanly and matched nothing (rg exits 1)
absent() { local rc=0; rg -q --hidden --glob '!.git' "$@" || rc=$?; [ "$rc" -eq 1 ]; }
cd rn-forge/kiln/tests/fixtures/golden
absent 'def main' python-app/src python-tool/src                                      # S3.1.1
rg -q '^golden-app = "golden_app\.main:app"$' python-app/pyproject.toml               # S3.1.1
rg -q '^golden-tool = "golden_tool\.main:app"$' python-tool/pyproject.toml            # S3.1.1
for g in python-app:golden-app python-tool:golden-tool; do
  (cd "${g%%:*}" && uv sync && uv run "${g##*:}" --help >/dev/null && task validate) \
    || { echo "FAIL ${g%%:*}" >&2; exit 1; }                                          # S3.1.1
done
absent 'rn_forge\.cli\.declare|build_app|from rn_forge\.cli import console' python-app python-tool  # S3.1.2
absent 'log_options|output_options' python-app python-tool                            # S3.1.3
```
