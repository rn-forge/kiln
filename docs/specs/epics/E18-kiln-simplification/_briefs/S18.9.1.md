# S18.9.1 — The docs module

Brief for [S18.9.1](../F18.9-large-files-split.md#s1891-the-docs-module), at
`fef6689`. The feature page's line numbers are stale: find each named function
by name. Paths are under `src/rn_forge/kiln/modules/docs/`.

## Goal

Split the docs module's files and functions so each does one job. No file under
`modules/docs/` is over 400 lines and no function is over 60. No rendered file,
finding, message or exit code changes.

## Settled

- **`work.py` becomes the package `work/`.** `work/model.py` holds the
  dataclasses, `load_work` and the metadata reading. `work/validate.py` holds
  `validate`, split into `_validate_epic`, `_validate_feature` and
  `_validate_release` around one `_Report` dataclass (the findings list, an
  `err(...)` method and the `rel(...)` path helper), replacing the closures
  and the two `err` copies inside today's `validate`. `work/render.py` holds
  the renderers, sharing one `_counts`, one `_cell` and one `_body` where
  today repeats them. `work/__init__.py` re-exports exactly today's
  `work.__all__`, so `from rn_forge.kiln.modules.docs.work import X` keeps
  working everywhere.
- **`title_markup`, `epic_range` and `range_label` move to `parsed.py`**, and
  `nav.py` imports them from there, not from `work`. `nav.py` keeps building
  the work nav from `load_work`'s result.
- **`generate.py`'s regions.** Today `_work_regions` (99 lines) returns 3-tuples
  built in closures. It becomes one `Region(path, text, stale, markers)`
  dataclass list, built from a table of `(page, block, renderer, name)` rows.
  `generate` writes the regions and `stale` reports them. The `ci_matrix=`
  parameter (S18.8.2) stays as it is.
- **`packages.py`'s mkdocs plumbing** (`read_mkdocs`, `excluded_docs`,
  `package_mounts`, `resolve_link`) moves to a new `mkdocs.py`. `packages.py`
  and its other callers import it from there.
- **`artifacts.py`**: one archetype-to-excluded-prefixes table replaces the
  `_PACKAGE_SITE_SKIPS`/`_PYTHON_LIB_ONLY` tuples and the `if` that picks
  between them.
- **`site.py` `check_links`** (66 lines) splits into helpers, so it is at most
  60 lines.
- **Docstrings** in every file this story touches state the contract only.
  `policy.py`'s module docstring loses its rationale and the `(D44)` tag, and
  every ADR reference, decision tag and design note in a touched file goes.
- **Test imports**: a test that imports a moved name (e.g. `read_mkdocs` from
  `packages`) imports it from its new module. That is the only allowed test
  edit.
