## S6.1.1 — A pykit-shaped repository passes its own gate

**Status:** planned

Build a scratch `python-lib` repository with the shape that makes pykit hard to
host:

- Seven packages named as pykit's are: `rn-forge-commons`, `rn-forge-cli`,
  `rn-forge-tooling`, `rn-forge-web`, `rn-forge-django`, `rn-forge-fastapi`
  and `rn-forge-sqlalchemy`. Each is added with `kiln generate package`.
- The workspace dependencies run cli → commons, tooling → cli, and web, django,
  fastapi and sqlalchemy → commons, all as `{ workspace = true }`.
- Three of the member names are also dependencies of `rn-forge-kiln`. The root
  sets `[tool.uv] override-dependencies` so that kiln resolves to the
  workspace copies ([ADR-0006](../../../adr/ADR-0006.md)).
- A root guide links a page in each package's site.

The script that builds it lives at `tests/e2e/pykit_shape.sh`. It takes the
scratch directory and the kiln checkout as arguments. Any failure that also
reproduces in an empty `python-lib` repository is fixed in kiln, with a
regression test, before this story continues.

**Acceptance:**

- `tests/e2e/pykit_shape.sh` builds the repository from a fresh `kiln new`, with
  `origin` set to `https://github.com/rn-forge/pykit-shape`, and with no edits
  to generated files.
- In it, `uv sync`, `task validate` and `kiln doctor --full` pass.
- Its `uv.lock` records `rn-forge-kiln`, and `rn-forge-tooling` resolves to the
  editable workspace member.
- Its generated nav includes all seven package sites, and the root guide's links
  into them pass `docs-structure` and `docs-site`.
- This story records the kiln ref it passed at.

## Acceptance

```bash
set -euo pipefail
cd rn-forge/kiln
s=$(mktemp -d)
tests/e2e/pykit_shape.sh "$s/pykit-shape" "$PWD"                                      # S6.1.1
cd "$s/pykit-shape"
rg -q '^archetype = "python-lib"' .rn-forge/kiln/config.toml                         # S6.1.1
[ "$(rg -o '"packages/rn-forge-[a-z]+"' .rn-forge/kiln/config.toml | sort -u | wc -l)" -eq 7 ]  # S6.1.1
uv sync
task validate                                                                         # S6.1.1
rg -q '^name = "rn-forge-kiln"$' uv.lock                                             # S6.1.1
rg -A2 '^name = "rn-forge-tooling"$' uv.lock | rg 'editable = "packages/rn-forge-tooling"' >/dev/null  # S6.1.1
uv run kiln doctor --full                                                             # S6.1.1
```
