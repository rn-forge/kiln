# S16.11.1 — The Sonar organisation and project key come from the config

Brief for
[S16.11.1](../F16.11-identity-follows-the-config.md#s16111-the-sonar-organisation-and-project-key-come-from-the-config),

## Goal

`sonar-project.properties` names the SonarCloud organisation from
`[ci] sonar_organization`, or else `[repository] owner`, and the project key is
`<organisation>_<name>`.

## Settled

All settled by the owner on 2026-11-19.

- **The key.** Add a field to `CiConfig` in
  `src/rn_forge/kiln/modules/cicd/config.py`, after `sonar` (line 195):

    ```python
    sonar_organization: str | None = None
    """The SonarCloud organisation the analysis reports to. Changing it rewrites
    the Sonar properties on `kiln apply`. Default: `[repository] owner`."""
    ```

    Add a `field_validator("sonar_organization")` that refuses an empty or
    whitespace-only string with
    `ValueError("ci.sonar_organization must be non-empty")`. `None` is allowed.

- **The render.** In `src/rn_forge/kiln/modules/cicd/artifacts.py`:

    - remove `SONAR_ORGANIZATION` (lines 20-21) and its `__all__` entry (line 18);
    - set `"organization": ci.sonar_organization or config.owner` in the context
      (line 112). `KilnConfig.owner` is at `src/rn_forge/kiln/config.py:71`.

- **The template.** In
  `src/rn_forge/kiln/modules/cicd/templates/sonar-project.properties.j2`, line

- **Docs.** In `docs/reference/standard-repo.md`'s `[ci]` example (around line

## Current behaviour

- `artifacts.py:20` hard-codes `SONAR_ORGANIZATION = "rn-forge"`, and the
  template hard-codes the `rn-forge_` prefix, so every repository renders
  `sonar.organization=rn-forge` and `sonar.projectKey=rn-forge_<name>`.
- `CiConfig` forbids unknown keys, so today `sonar_organization = "acme"` fails
  `KilnConfig.load` with a `ModelValidationError` (extra field), not a render.
- `tests/modules/cicd/test_sonar.py` builds repositories with
  `_sonar_root(tmp_path, archetype, extra)`. `extra` is added to `[ci]` by
  `_with_ci` (`tests/modules/cicd/support.py:146`). `tests/conftest.py`'s
  `CONFIG` writes `owner = "rn-forge"` (line 32). `SONAR_BEFORE` and
  `test_empty_lists_render_what_the_archetype_rendered_before` pin the
  `rn-forge` output byte for byte, and must still pass unchanged.
