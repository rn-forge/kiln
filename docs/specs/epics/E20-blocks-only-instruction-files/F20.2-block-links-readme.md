A fresh `AGENTS.md` holds only kiln's block, and nothing in it points at
`README.md`, where ADR-0020 puts what the repository is and how to set it up.
The block's "Docs rules" bullet already leads to `docs/index.md`, which links
the spec board and the decision log, and the standard already says the body is
the owner's. So the block needs one clause, not a new section, and kiln seeds no
body and no page of suggested sections.

## S20.2.1 — The block's opening paragraph links `README.md`

**State:** New

**Acceptance:**

- The opening paragraph of `modules/instructions/templates/block.md.j2` reads,
  in every archetype and docs profile:

    ```markdown
    This repo is generated and checked by [kiln](https://github.com/rn-forge/kiln).
    What it is and how to set it up are in [README.md](README.md). The standard,
    rendered for this repo's archetype and docs profile, is
    [.rn-forge/kiln/standard.md](.rn-forge/kiln/standard.md). Read it before
    changing anything structural.
    ```

- A test renders the block for `mkdocs`, `external` and `none` and finds
  `[README.md](README.md)` in each.

- kiln's own `AGENTS.md` block is regenerated by `task kiln:apply`, and
  `task validate KILN_DOCTOR_FULL=1` passes.
