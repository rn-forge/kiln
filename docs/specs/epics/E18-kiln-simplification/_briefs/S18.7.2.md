# S18.7.2 — State identity is declared once

## Goal

`modules/core/umbrella.py` owns the state file's path and its schema version;
every other module imports them. No rendered file changes.

## Settled

- `umbrella.py` gains `STATE_SCHEMA_VERSION = "1"`, added to its `__all__`.
  `STATE_PATH = UMBRELLA / "state.json"` (`:24`) stays the one literal.
- `umbrella.py:62` (`tree / "state.json"`, inside `_declares_schema_version`)
  becomes `tree / STATE_PATH.name`.
- `cycle.py` imports `STATE_SCHEMA_VERSION` from `umbrella` and deletes its own
  (`:45`), dropping it from its `__all__` if listed. `cycle.SCAFFOLDED_KEY`
  stays where it is.
- `modules/core/checks/generated.py:34-35` (`STATE_PATH`, `SCHEMA_VERSION`),
  `modules/core/config/manager.py:53` (`_STATE_PATH`) and
  `modules/tasks/checks/layout.py:38` (`STATE_PATH`) delete their constants
  and use `umbrella.STATE_PATH` and `umbrella.STATE_SCHEMA_VERSION`. A test
  that imported a deleted name imports it from `umbrella` instead; that is the
  only test edit allowed.
- `modules/core/config/schema.py:28` `SCHEMA_VERSION = 1` is the **config**
  schema version, a different fact. Leave it.
