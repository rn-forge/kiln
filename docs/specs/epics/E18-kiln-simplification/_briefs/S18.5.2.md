## Goal

Replace the setup code copied across the suite with one shared support layer, so
that later refactors change one fixture rather than fifteen. Tests change;
`src/` does not.

## Settled

- **Tests only**, and **no test is deleted or weakened** (F18.5 properties). The
  collected count is unchanged, except where this story merges tests by
  parametrizing them; then the parameter count makes up the difference
  exactly.
- **Check tests go through the registry**, so an unregistered check fails its
  own tests. The one exception is `tests/modules/core/checks/test_pin.py`:
  `modules/core/checks/pin.py` is not in `checks.CHECKS`
  (`src/rn_forge/kiln/checks.py:47`) until F18.10. It keeps its direct calls
  and gains one `xfail(strict=True)` test that runs `pin` through `run_check`.
- Shared helpers live in `tests/conftest.py`, except the cicd `workflows`
  fixture, which lives in `tests/modules/cicd/conftest.py` (story text).

## Change

- **Change:**
    - `tests/conftest.py`: extend `repo` to take `release`, `sonar`, `frontend`,
      `backend`, `packages` and a `tail` of extra TOML, and convert the files
      above to it. Add `rendered_copy(archetype)` (copies `rendered(archetype)`
      with one shared ignore pattern), `git(cwd, *args)`, `snapshot(*roots)`,
      `actions(root, tmp_path)` and `run_check(name, root)`, which looks the
      check up in `checks.CHECKS` and runs it. Where two copies of a helper
      differ (for example `_snapshot` returns `str` in one file and `bytes` in
      another), the shared one takes the stricter form (`bytes`) and callers
      adapt; record each such choice in `## Result`.
    - Move `MISSING_REQUIRED` to the support layer and drop `_load` from
      `tests/test_doctor.py`.
    - `tests/modules/cicd/conftest.py`: a `workflows` fixture replaces the three
      loaders.
    - Switch the 14 check test files to `run_check`; `test_pin.py` as **Settled**.
    - Parametrize the two `tests/test_new.py` groups.
    - Guard tests in `tests/test_conftest.py`:
      `test_s18_5_2_1_no_test_loads_another_by_path` (no
      `spec_from_file_location` under `tests/` except the `scripts/` loader in
