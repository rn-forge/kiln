# S18.5.1 — Tests reach `commands` only through its public names

Brief for
[S18.5.1](../F18.5-tests-survive-a-refactor.md#s1851-tests-reach-commands-only-through-its-public-names),
at `21c8dc4`.

## Goal

Make the tests call and patch `rn_forge.kiln.commands` only through its public
names, so that F18.6 can turn `commands.py` into a package without a test
silently losing its patch. Tests change; `src/` does not.

## Settled

- **Tests only.** No file under `src/` changes (F18.5's opening paragraph).
- **No test is deleted or weakened, and the collected count is unchanged**
  (F18.5 property 1). A test that moves keeps its body.
- **The scaffold-step patches stay on `commands`, listed.** `commands.py` binds
  the scaffold steps with `from … import`
  (`src/rn_forge/kiln/commands.py:46-62`), so a patch at the definition does
  not reach `new`. The story says such a case is recorded and S18.6.2 changes
  the imports to module imports. Lead's ruling, 2026-11-14: the guard test
  below carries an explicit allowlist of the test functions that still patch
  `commands`, with a comment that S18.6.2 empties it. Nothing else may be on
  it.
- **A private name that cannot be replaced** by a test through `commands.new` or
  `commands.apply` goes on the same allowlist, by test name, and moves with
  the name in S18.6.2.

## Current behaviour

- `tests/conftest.py:183-206`: the autouse `_default_owner` fixture wraps
  `commands.new` with `owner="rn-forge"` for every test, via
  `monkeypatch.setattr(commands, "new", …)`. Tests opt out with the
  `ownerless` fixture (`:210-211`).
- Patches on `commands`: `instructions_scaffold` (`tests/test_new.py:479`,
  `:548`), `python_add_package` (`:875`), and `scaffold_backend`,
  `reconcile_backend`, `scaffold_node`, `reconcile_node`, `format_node`
  (`:1151-1166`).
- `ConfigManager` reached through `commands`: `tests/test_new.py:190`, `:215`;
  `tests/modules/cicd/test_artifacts.py:2705`.
- Private names: `commands._FLAG_NAMES` (`tests/test_new.py:58`),
  `commands._flag_layer` (`tests/test_new.py:114`, `:121`, `:182`, `:206`,
  `:223`; `tests/modules/cicd/test_artifacts.py:2697`),
  `commands._CONFIG_HEADER` (`tests/test_new.py:788`),
  `commands._write_config` (`tests/modules/core/test_catalog.py:27`),
  `commands._fail_on_errors` (`tests/test_doctor.py:484`, `:488`), and
  `inspect.getsource(commands._stage)` (`tests/test_new.py:586`).

## Change

- **Change:**
    - `tests/conftest.py`: replace `_default_owner` and `ownerless` with a plain
      helper `new_repo(directory, **kwargs)` that calls `commands.new` with
      `owner` defaulting to `"rn-forge"`. Every call of `commands.new` that has
      no `owner=` becomes `new_repo(...)` (this includes the `rendered` fixture
      at `:133`). Tests that check the owner rule, the ones that now request
      `ownerless`, call `commands.new` directly and drop the fixture.
    - The `ConfigManager` imports: from
      `rn_forge.kiln.modules.core.config.manager`.
    - Each private name: test the same behaviour through `commands.new` or
      `commands.apply` (for example, `_flag_layer` through the config `new`
      writes; `_write_config`/`_CONFIG_HEADER` through the written
      `.rn-forge/kiln/config.toml`; `_fail_on_errors` through `commands.apply`
      raising `AppException`). Where that is not possible, keep the test and add
      it to the allowlist.
    - `tests/test_new.py:586`: replace the `getsource` assertion with a
      behavioural check that `RNF_HOME` is not set in the staged run (for
      example, record `os.environ` from a patched step the test already patches,
      or from a step on the allowlist).
    - New guard test, `tests/test_conftest.py` (or a new
      `tests/test_commands_surface.py`):
      `test_s18_5_1_1_tests_use_only_public_commands_names`. It scans every
      `tests/**/*.py` for `commands\._[A-Za-z]` and for
      `monkeypatch.setattr(commands`, and fails on any match outside the
      allowlisted test functions. The allowlist is a module constant naming each
      `<file>::<test>` with a comment: "S18.6.2 moves these and empties this
      list."
- **Leave alone:** everything under `src/`; the golden repos; tests that do not
  touch `commands`.
