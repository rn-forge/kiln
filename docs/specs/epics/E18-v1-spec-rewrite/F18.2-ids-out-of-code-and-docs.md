Removes the old IDs from everything outside `specs/`, so that renumbering in
[F18.3](F18.3-area-epics.md) leaves nothing dangling. It also removes
`docs/plans/` and cuts the release pages to summaries. Sonnet can build every
story.

## S18.2.1 — The source names no spec ID

**State:** New

**Acceptance:**

- No epic, feature or story ID appears under `src/`, in code, a template or a
  comment.
- The docstrings in `commands.py` hold only the contract, with no ADR reference
  or design rationale (defect 11).

## S18.2.2 — The ADRs, README, architecture, guides, reference and runbooks cite no feature or story

**State:** New

**Acceptance:**

- No feature or story ID appears in `docs/adr`, `docs/architecture`,
  `docs/guides`, `docs/reference`, `docs/runbooks` or `README.md`. Where a
  reference still helps, it becomes a sentence or a link to a page.
- No ADR loses a decision.

## S18.2.3 — Release pages summarise scope and status

**State:** New

**Acceptance:**

- Each release page holds its metadata table, a short paragraph on what the
  release carries, its derived Scope table, and its status. Explanation stays
  in the specs.
- No story ID appears under `docs/releases`.

## S18.2.4 — `docs/plans/` is gone

**State:** New

**Acceptance:**

- `docs/plans/` does not exist.
- `docs/_areas.yml` has no `plans` area, the site nav has no Plans section, and
  no page links into `plans/`.
- The "Why things are the way they are" convention in `specs/index.md` points at
  nothing that was removed.
- `GOVERNANCE_AREAS` in `modules/docs/packages.py` still lists `plans` for other
  repositories, unless the build shows that kiln itself depends on it.

## Acceptance

```bash
set -euo pipefail
absent() { local rc=0; rg -q --hidden --glob '!.git' "$@" </dev/null || rc=$?; [ "$rc" -eq 1 ]; }
absent -e '\b[EFS][0-9]+\.[0-9]+(\.[0-9]+)?\b' src                         # S18.2.1
absent -e '\b[FS][0-9]+\.[0-9]+(\.[0-9]+)?\b' docs/adr docs/architecture \
  docs/guides docs/reference docs/runbooks README.md                       # S18.2.2
absent -e '\bS[0-9]+\.[0-9]+\.[0-9]+\b' docs/releases                       # S18.2.3
test ! -e docs/plans                                                       # S18.2.4
absent -e '\]\([^)]*plans/' docs README.md                                 # S18.2.4: no link
absent -F 'plans/' mkdocs.yml                                              # S18.2.4
absent -F 'key: plans' docs/_areas.yml                                     # S18.2.4
task docs:generate
task validate
```

Not scripted: the docstrings in `commands.py` hold only the contract (S18.2.1),
and no ADR loses a decision (S18.2.2).
