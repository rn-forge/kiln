# S18.5.4 — Test files follow the source, by subject

Brief for
[S18.5.4](../F18.5-tests-survive-a-refactor.md#s1854-test-files-follow-the-source-by-subject),
at `21c8dc4`. S18.5.1 to S18.5.3 land before this story and edit the files it
splits; locate code by name and banner, and treat line counts as a guide.

## Goal

Split the oversized, story-banner-organised test files into files by subject,
and move the command tests under `tests/commands/`, so F18.1's renames land in
small files. Tests move; their bodies do not change.

## Settled

- **Tests only**, and **no test is deleted or weakened**. A test that moves
  keeps its name and its body. The collected count is unchanged.
- **The split is by subject, not by story.** Banners `# S<id> — …` go. Topic
  file names follow the story text: `test_workflow_security.py`,
  `test_node_ci.py`, `test_sonar.py`, `test_release.py`, `test_pages.py` are
  examples; pick the subjects the banners group into, and name each file for
  its subject. List the mapping (banner → file) in `## Result`.
- **Destinations:** `tests/commands/` for `test_new_*.py` (flags, staging,
  owner, packages, node) and for `test_apply`, `test_diff`, `test_prompt`,
  `test_config_lifecycle`, `test_lifecycle`, `test_cli_surface`,
  `test_generate_package`. `tests/scripts/test_golden_matrix.py`.
  `tests/suite/` for `test_conftest.py` and `test_checks_are_render_free.py`.
- **`rendered` in place of a full render**: a read-only test in the new
  `test_new_*.py` files that calls `new_repo` (or `commands.new`) with no flag
  beyond `archetype`/`docs`, and never writes, uses the session `rendered`
  fixture. It keeps its name. Record each converted test in `## Result`.
- Shared helpers a split file needs come from the S18.5.2 support layer, never
  from a sibling test file (`--import-mode=importlib`, no test packages).

## Current behaviour

At `21c8dc4`: `tests/modules/tasks/test_artifacts.py` is 4,070 lines with 21
`# S` banners; `tests/modules/cicd/test_artifacts.py` is 3,712 lines with 18;
`tests/test_new.py` is 1,207 lines; `tests/test_golden_matrix.py` is 1,026.
Every other file under `tests/` is under 1,000 lines. Paths that tests compute
from `Path(__file__)` (for example `UV_FIXTURE` in `tests/test_new.py`, and
`TESTS`, `parents[...]` lookups) change depth when a file moves.

## Change

- **Change:** the files above, split or moved; any `Path(__file__)`-relative
  path in a moved file, fixed for its new depth; `tests/modules/*/conftest.py`
  only if a split needs a fixture the original file defined locally (move it
  to that directory's `conftest.py`).
- **Leave alone:** `src/`; test names and bodies; `pyproject.toml` `testpaths`
  (it already covers `tests/`).
