# S7.8.1 — Plan and write rn-forge range changes

## Goal

Provide the range planner and writer used by the target kiln during upgrade. The
coordinator in S7.8.2 owns changes to Git state, command execution and recovery.

## Settled

- **`archetypes.floor`.** Add `floor(requirement: str) -> str | None` to
  `src/rn_forge/kiln/archetypes/__init__.py`, next to `requirement()` (line
  168), and export it in `__all__`. It returns the lower bound a requirement
  declares:

    - The first `>=`, `==` or `~=` clause's version, matched by
      `(?:>=|==|~=)\s*(\d+(?:\.\d+)*)`, in the specifier part (before any `;`).
    - For a direct URL (`name @ git+…@<tag>`), the version from the tag's
      `-v(\d+\.\d+\.\d+)`.
    - `None` otherwise.

    Add a helper `version_key(version: str) -> tuple[int, ...]`, which splits on
    `.` and pads to three parts. Export it too.

- **New module `src/rn_forge/kiln/modules/python/ranges.py`.** Its `__all__` is
  `Move`, `plan`, `write` and `release_notes`.

    - `@dataclass(frozen=True) class Move`: `path: str` (POSIX-relative, as
      `archetypes.pyproject_paths` gives it), `distribution: str`, `old: str`,
      `new: str`, `old_floor: str | None`, `breaking: bool`. `breaking` is true
      when `old` had no ceiling equal to the new one: `old` is a URL pin, or its
      `<` clause differs from `<{archetypes.ceiling(table_version)}`.

    - `plan(config: KilnConfig, root: Path) -> list[Move]`. It goes through each
      path in `archetypes.pyproject_paths(config)` that exists, and through
      every string in these three places:

        - `[project] dependencies`
        - each `[project.optional-dependencies]` list
        - each `[dependency-groups]` list

        Entries that are not strings, such as `{ include-group = … }`, are skipped.
        An entry moves when all of these hold:

        - `rn_forge_deps.governed(name)` is true.
        - `name` is a key of `archetypes.RN_FORGE_TAGS`.
        - `name` is not in `rn_forge_deps.workspace_members(config, root)`.
        - `floor(entry)` is `None` or its `version_key` is below the table
          version's.

        `name` is `rn_forge_deps.distribution(entry)`; import both helpers from
        `rn_forge.kiln.modules.python.checks.rn_forge_deps`. Moves come in file
        order, then entry order.

    - **The new string** is built from the entry. Take the name as written; the
      extras group `[...]` if present, verbatim; and the marker after `;` if
      present, stripped. The result is
      `f"{name}{extras}>={version},<{ceiling(version)}"`, plus `f"; {marker}"`
      when there is a marker. `version` is the table tag's `-v` suffix, the same
      way `requirement()` gets it. Example:
      `rn-forge-commons[pydantic]>=0.9.0,<0.10; python_version >= "3.12"`
      becomes
      `rn-forge-commons[pydantic]>=0.10.0,<0.11; python_version >= "3.12"`. A
      URL entry such as
      `rn-forge-cli @ git+https://github.com/rn-forge/pykit@rn-forge-cli-v0.1.3#subdirectory=packages/rn-forge-cli`
      becomes `rn-forge-cli>=0.2.0,<0.3`.

    - `write(root: Path, moves: list[Move]) -> None`. For each path, it reads with
      `DocumentUtils.read_document`, replaces each array item equal to
      `move.old` in the same three places with `move.new` (index assignment on
      the tomlkit array), and writes with `DocumentUtils.write_document`. It
      does not call `tidy` and reorders nothing.

    - `release_notes(move: Move) -> str`. The URL is
      `f"https://raw.githubusercontent.com/rn-forge/pykit/{RN_FORGE_TAGS[d]}/packages/{d}/CHANGELOG.md"`.
      Fetch it through a module-level `_fetch(url: str) -> str | None`, which
      uses `urllib.request.urlopen(url, timeout=10)` and decodes UTF-8. It
      returns `None` on `OSError`, which covers `URLError`. On `None`, return
      `f"release notes: {url}"`. Otherwise return the `## [X.Y.Z]` sections,
      each heading through to the line before the next `## `, whose version is
      above `move.old_floor` (all of them when that is `None`) and at or below
      the table version. Join them with a blank line. `## [Unreleased]` is never
      included.

## Tests first

`tests/test_archetypes.py`:

1. `test_floor_reads_a_range_a_pin_and_a_url`. Each of these returns the version
   shown:
    - `rn-forge-commons>=0.9.0,<0.10` returns `0.9.0`.
    - `rn-forge-web[auth]==0.3.1` returns `0.3.1`.
    - `rn-forge-cli @ git+https://github.com/rn-forge/pykit@rn-forge-cli-v0.1.3#subdirectory=packages/rn-forge-cli`
      returns `0.1.3`.
    - `rn-forge-commons` returns `None`.
    - `rn-forge-commons<0.10` returns `None`.

`tests/modules/python/test_ranges.py` builds its repositories with
`rendered_copy("python-tool")`, and with `rendered_copy("python-lib")` for the
workspace cases. It writes the `pyproject.toml` entries under test with
`DocumentUtils`.

1. `test_an_old_range_moves_to_the_pin_table`: `rn-forge-commons>=0.9.0,<0.10`
   plans one move whose `new == archetypes.requirement("rn-forge-commons")`
   and whose `breaking` is true.
1. `test_a_move_keeps_extras_and_marker`: the extras-and-marker example in
   Settled.
1. `test_a_git_pin_becomes_a_range`: the URL example in Settled.
1. `test_a_floor_at_or_above_the_table_is_left_alone`: an entry equal to
   `requirement(name)`, and one whose floor is a patch above it, plan nothing.
1. `test_non_rn_forge_and_workspace_members_are_left_alone`: `httpx>=0.28`, and
   a python-lib member named in another member's dependencies, plan nothing.
1. `test_groups_and_optional_dependencies_move`: an old entry in
   `[dependency-groups] dev` and one in `[project.optional-dependencies] x`
   both move, and an `{ include-group = "workspace" }` entry is skipped.
1. `test_write_changes_only_the_moved_strings`: after `write`, the file's text
   equals the original text with each `old` replaced by `new`.
1. `test_release_notes_are_the_sections_between_the_floors`: monkeypatch
   `ranges._fetch` to return a changelog with `[Unreleased]`, `[0.10.0]`,
   `[0.9.1]` and `[0.9.0]` sections. With `old_floor="0.9.0"`, the result
   holds the `0.10.0` and `0.9.1` headings and neither `0.9.0` nor
   `Unreleased`.
1. `test_unreachable_release_notes_give_the_url`: `_fetch` returns `None`, and
   the result starts with
   `release notes: https://raw.githubusercontent.com/rn-forge/pykit/`.
