# S7.8.2 — `task kiln:upgrade`

Brief for
[S7.8.2](../F7.8-existing-repos-take-the-pin-table.md#s782-task-kilnupgrade), at
`dcfe75c` plus S7.8.1. Line references are at `dcfe75c`.

## Goal

Render a public `kiln:upgrade` task next to `kiln:pin`. It checks that the
working tree is clean, pins kiln, and then runs `kiln apply` and
`kiln deps-upgrade --tree-checked` with the kiln at the new ref. Document it as
the way a repository takes a new kiln's pykit floors.

## Settled

All settled by the owner on 2026-11-18. See the feature's `## Design`.

- **The task.** Add it to
  `src/rn_forge/kiln/modules/tasks/templates/tasks/kiln.yml.j2`, inside the
  same `{% if not kiln_own %}` block as `pin` (lines 29-35), after `pin`:

    ```yaml
      upgrade:
        desc: Pin kiln (a ref after `--`, or follow `track`), re-render, move the rn-forge ranges to its pin table and run `task validate`; a failure rolls back to HEAD unless FORCE=1.
        preconditions:
          - sh: test -z "$(git status --porcelain)"
            msg: kiln:upgrade needs a clean working tree, so a failed upgrade can roll back to HEAD — commit or stash first
        cmds:
          - '{{.KILN}} pin{{if .CLI_ARGS}} --ref {{.CLI_ARGS}}{{end}}'
          - 'uvx --from "rn-forge-kiln @ [[ kiln_git ]]@$({{.KILN}} pin --show)" kiln apply'
          - 'uvx --from "rn-forge-kiln @ [[ kiln_git ]]@$({{.KILN}} pin --show)" kiln deps-upgrade --tree-checked{{if .FORCE}} --force{{end}}'
    ```
