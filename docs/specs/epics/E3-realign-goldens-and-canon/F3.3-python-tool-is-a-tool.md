# F3.3 — Make `golden/python-tool` a tool

Epic: [E3](index.md) · Decision: [ADR-0005](../../../adr/ADR-0005.md) ·
**Depends on:** [F3.1](F3.1-goldens-on-part-e-api.md), and pykit's lifecycle
surface (`rn_forge/tooling/install/` + `[cli.lifecycle]`) — see
[upstream work owned by pykit](../../index.md#upstream-work-owned-by-pykit)

## S3.3.1 — The golden declares and implements the lifecycle

**Status:** done

It declares `[cli.lifecycle]` and implements `ToolProduct` in one small module
(`artifacts()` returning its one global artifact, one `checks()` row).
`[cli.lifecycle]` names the product and pykit's required `target`,
`rn_forge.tooling.cli.lifecycle:lifecycle_commands`; `--json` is a root option,
so it precedes the verb. Built against pykit `757908e`.

**Acceptance:**

- Exactly one module under `src/` implements `ToolProduct`.
- `golden-tool doctor` exits 0, and its report includes the product's own check
  row.
- `golden-tool --json status` has a `.version`.
- The golden's tests cover `artifacts()` and `checks()`, and `task validate`
  passes.

## S3.3.2 — The flag is the only difference

**Status:** done

Its `config.toml` records `archetype = "python-app"` + `lifecycle = true`.
`golden/python-app` gains no `$RNF_HOME` or lifecycle reference — the diff
between the two is the flag and nothing else.

**Acceptance:**

- `golden/python-tool`'s config records `archetype = "python-app"` and
  `lifecycle = true`.
- Nothing in `golden/python-app` matches `RNF_HOME` or `lifecycle`.
- A recursive diff of the two goldens, with the package name normalized, shows
  only: the flag, `[cli.lifecycle]`, the `ToolProduct` module and its test,
  and the `rn-forge-tooling` dependency. The reviewer checks this list before
  the story is marked done.

Reviewed 2026-09-15. The diff carried three findings outside that list, each
fixed rather than accepted: `greet()` rendered through `TemplateEngine` from a
`src/golden_tool/templates/` tree, which `product.py` now makes redundant —
removed, so `greet` is the same function in both goldens; `main.py`'s docstring
carried an `$RNF_HOME` aside — reverted, so `main.py` is byte-identical modulo
the package name; and the tool's `README.md` had dropped the shared CLI design
sentence the app's carries — restored, with the lifecycle named alongside it.
What remains is the list above, plus archetype-descriptive prose and the files
rendered from `config.toml` (`standard.md`, `state.json`, `uv.lock`).
