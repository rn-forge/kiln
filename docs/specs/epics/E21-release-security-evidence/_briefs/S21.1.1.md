# S21.1.1 — The control catalog

Brief for [S21.1.1](../F21.1-evidence-record.md#s2111-the-control-catalog), at
`feature/v1` after `5eeea81a`.

## Goal

kiln has one catalog of the security controls a release's evidence record
reports, built from the check registry, and the rendered standard shows it under
the CI checks matrix.

## Settled

- New module `src/rn_forge/kiln/modules/cicd/controls.py`, exporting (`__all__`)
  `CONTROLS`, `Effect`, `SecurityControl`, `Source` and `render_catalog`:

    ```python
    class Effect(StrEnum):
        FAILS = "fails the build"
        BLOCKS_PUSH = "blocks the push"
        REPORTS = "reports only"


    class Source(StrEnum):
        LINT_JOB = "lint-job"
        JOB = "job"
        NOT_CHECKED = "not-checked"
        RELEASE_ASSET = "release-asset"
        ATTESTATION = "attestation"
        FILE = "file"
        SCORECARD_RUN = "scorecard-run"


    @dataclass(frozen=True)
    class SecurityControl:
        name: str
        effect: Effect
        source: Source
        result_from: str
        evidence: str
        checks: tuple[str, ...] = ()
    ```

    `checks` holds the registry `CiCheck.name`s whose result the control reports.
    `Source` is what S21.1.2's collector dispatches on; this story only declares
    it.

- `render_catalog(archetype: str) -> str` returns a Markdown table with header
  `| Control | Effect | Result from | Evidence |` and the separator style of
  the matrix. Reuse the registry's helpers rather than copying them: in
  `registry.py`, rename `_table` to `table` and `_name_cell` to `name_cell`,
  add both to `__all__` with a docstring each, and update their callers
  (`render_matrix`, and `tests/modules/cicd/test_registry.py:133`, whose
  `pyright: ignore` comment then goes). One row per control, in `CONTROLS`
  order, every control always listed. The Control cell is the control's name,
  followed, when the archetype runs any of the control's `checks`
  (`archetype in check.archetypes`), by those checks in the control's order,
  each formatted with `registry.name_cell`, comma-separated in parentheses:
  e.g. `` Dependency audit (`pip-audit`, `pnpm-audit`) `` for `python-web-app`,
  `` Dependency audit (`pnpm-audit`) `` for `node-lib`, `Push protection`
  alone. The Effect cell is the `Effect` value; the other two cells are the
  texts.

- In `registry.py`, `CiCheck` gains `security: bool = False`. Set it `True` on
  exactly: `ruff check and format`, `pip-audit`, `pnpm-audit`,
  `Nx lint, typecheck, test, build`, `licenses`, `secret-scan`, `scorecard`
  (use `dataclasses.replace(..., security=True)` for `_std` rows, the keyword
  for `CiCheck(...)` rows). Nothing else in the registry changes, and the
  rendered matrix does not change.

- `KilnConfig` (`src/rn_forge/kiln/config.py`) gains, next to `ci_matrix`:

    ```python
    def security_controls(self) -> str:
        """The security control catalog for this archetype."""
        return controls.render_catalog(self.archetype)
    ```

    and `instructions/artifacts.py` `context()` gains
    `"security_controls": config.security_controls(),` after `ci_matrix`.

- In `src/rn_forge/kiln/modules/instructions/templates/standard.md.j2`, right
