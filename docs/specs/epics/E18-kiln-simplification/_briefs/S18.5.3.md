# S18.5.3 — Tests that need a live tool are marked

Brief for
[S18.5.3](../F18.5-tests-survive-a-refactor.md#s1853-tests-that-need-a-live-tool-are-marked),
at `21c8dc4`.

## Goal

Every test that needs an external tool on `PATH` carries a marker, so a run can
select or deselect them, and the skip rule lives in one helper. Tests change;
`src/` does not.

## Settled

- **Tests only**, and **no test is deleted or weakened**; the collected count is
  unchanged (F18.5 properties).
- **Three markers**: `requires_task`, `requires_pnpm`, `requires_tool`.
  `requires_tool` covers every other binary (`actionlint`, `zizmor`, `jq`,
  `node`, `git`, `bash`, `taplo`, `uv`). A test needing `task` plus another
  tool carries both markers.
- **One helper**, `requires(tool)` in `tests/conftest.py`, returns the marker
  and the `skipif` together (a `pytest.MarkDecorator` combination usable as a
  decorator, as a `pytest.param(..., marks=...)` entry and as `pytestmark`).
- **pnpm keeps its rule**: absence skips only when `CI` is unset; in CI a
  missing `pnpm` fails.
- In-body `if shutil.which(...) is None: pytest.skip(...)` becomes the decorator
  on the test; behaviour is the same skip.
