# S18.12.2 — A custom `web_dir` has one Nx project name

Brief for
[S18.12.2](../F18.12-release-1-review-defects.md#s18122-a-custom-web_dir-has-one-nx-project-name),
at `e776e90`. Paths are under `src/rn_forge/kiln/`.

## Goal

A `python-web-app` with `web_dir = "apps/portal"` names one Nx project
everywhere: `project.json`, the tasks, the Sonar properties and `AGENTS.md`.
`task web:build` runs in it.

## Settled

- **The Nx project is always `web`** (lead's ruling, 2026-11-17). The Angular
  scaffold creates it as `web` (`modules/node/angular.py:118`, `--name=web`),
  and `remove_scaffold_app` removes it by that name (`:167`). Moving the app
  to a custom `web_dir` (`node/scaffold.py` `_place_app`, `_rewrite_app_dir`)
  rewrites its paths but not its name. Renaming the project would also mean
  rewriting its targets (`web:build`), output and coverage paths, so the
  project keeps its name, and every module reads that one name. The default
  `web_dir = "apps/web"` renders exactly as today.
- **One owner**: `WEB_PROJECT = "web"` in `modules/node/angular.py`, added to
  its `__all__`, used for `--name=` and by `remove_scaffold_app`.
  `KilnConfig.web_project` (S18.7.1) returns `WEB_PROJECT` for a
  `python-web-app` and `None` otherwise. `config.py` may import from
  `modules/node/angular.py`, since the independence contract ignores
  `rn_forge.kiln.config -> rn_forge.kiln.modules.**`.
- **Every reader uses `config.web_project`**: `cicd/artifacts.py` (delete
  `_WEB_PROJECT`, `:29`; context `:128`), `tasks/artifacts.py:132` (already),
  and `instructions/artifacts.py:197` and `:243` (today `Path(web_dir).name`).
- `tests/test_config_owners.py` `test_s18_7_1_5_web_project_keeps_both_answers`
  pinned the two answers until this story. It becomes
  `test_s18_7_1_5_web_project_is_the_nx_project`: with
  `web_dir = "apps/portal"`, `config.web_project == "web"`. That is the one
  allowed edit to an existing test.

## Current behaviour

- With `web_dir = "apps/portal"`: the Nx project is `web`; `tasks/web.yml`
  serves `portal` (`nx serve [[ web_project ]]` with `Path(web_dir).name`);
  `AGENTS.md` and `standard.md` say "project `portal`"; the Sonar properties
  use `coverage/web/lcov.info`.
